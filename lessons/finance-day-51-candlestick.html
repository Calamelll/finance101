กราฟแท่งเทียน (candlestick)

แท่งเทียนหนึ่งแท่งสรุปราคาทั้งช่วงเวลาไว้ด้วยตัวเลขสี่ตัว วันนี้เรียนวิธีอ่านมัน และทดสอบด้วยการจำลองว่ารูปทรงสวยๆ ที่ตำราตั้งชื่อให้ ทำนายอะไรได้จริงหรือเปล่า

ตัวเลขสี่ตัวใน 1 แท่ง

แท่งเทียนคือการบีบข้อมูลราคาทั้งช่วงเวลา (1 นาที 1 ชั่วโมง 1 วัน) ให้เหลือสี่ค่า เรียกรวมว่า OHLC: ราคาเปิด (Open) ราคาสูงสุด (High) ราคาต่ำสุด (Low) และราคาปิด (Close) ส่วนที่เป็นกล่อง เรียกว่า ตัวเทียน (body) ครอบระหว่างราคาเปิดกับปิด ส่วนเส้นบางที่ยื่นออกไปคือ เงา (shadow หรือ wick) ไปจนถึงราคาสูงสุดและต่ำสุด ถ้าปิดสูงกว่าเปิดเรียกแท่งขึ้น (ในบทนี้ใช้สีเขียว) ถ้าปิดต่ำกว่าเปิดเป็นแท่งลง (สีแดง) สีเป็นแค่ธรรมเนียมของแต่ละแพลตฟอร์ม ตลาดแถบเอเชียตะวันออกบางแห่งใช้กลับกัน ให้ตรวจการตั้งค่าของกราฟที่ใช้เสมอ

แท่งเทียนต่างจากกราฟเส้นปิดรายวันตรงที่มีข้อมูลเพิ่มสามตัว (เปิด สูง ต่ำ) ที่เล่าว่าระหว่างวันราคาเดินไปไหนมาบ้าง ลองดูการประกอบแท่งจาก tick จริงทีละครั้งของหุ้น ก. (หุ้นสมมติ) เลื่อนสไลเดอร์แล้วดูว่า H และ L เปลี่ยนเมื่อไร:

แท่งจะ "ปิด" จริงก็ต่อเมื่อช่วงเวลานั้นจบ ระหว่างทางตัวเทียนและเงายังขยับได้ กราฟสดที่เห็นแท่งสุดท้ายกระดิกไปมาจึงเป็นเรื่องปกติ และเป็นเหตุผลว่าทำไมสัญญาณจากแท่งที่ยังไม่ปิดถึงเชื่อถือไม่ได้

อ่านรูปร่าง: สัดส่วนตัวเทียนต่อเงา

ข้อมูลที่ใช้ได้จริงมีไม่กี่ตัว: ช่วงราคา (range) = H − L, ตัวเทียน = |C − O|, เงาบน = H − max(O, C), เงาล่าง = min(O, C) − L และสัดส่วนตัวเทียน = ตัวเทียน ÷ range ตัวเลขนี้บอกว่าราคาที่ไปถึงระหว่างวันถูก "ยอมรับ" ที่ราคาปิดมากแค่ไหน ตัวเทียนยาวแปลว่าปิดใกล้ขอบของ range เงายาวแปลว่าราคาไปถึงแล้วถูกดันกลับ ลองปรับรูปร่างเองหรือกด preset:

รูปทรงที่มีชื่อ และสิ่งที่ตำราไม่ค่อยบอก

ชื่อหน้าตาตำราเล่าว่า
โดจิ (doji)เปิด ≈ ปิด ตัวเทียนบางเป็นเส้นตลาดลังเล อาจกลับตัว
ค้อน (hammer)ตัวเทียนเล็ก เงาล่างยาวอย่างน้อย 2 เท่าของตัว แทบไม่มีเงาบนราคาถูกกดลงแล้วถูกดันกลับ ลงสุดแล้ว
ดาวตก (shooting star)กลับด้านกับค้อน เงาบนยาวราคาถูกดันขึ้นแล้วถูกกดกลับ ขึ้นสุดแล้ว
แท่งไม่มีเงา (marubozu)ตัวเทียนเกือบเท่า rangeฝั่งเดียวคุมตลอดวัน
กลืนกิน (engulfing)ตัวเทียนวันนี้คลุมตัวเทียนเมื่อวานทั้งแท่ง ทิศตรงข้ามกันแรงฝั่งใหม่ชนะ กลับตัว

รูปทรงพวกนี้เป็นเครื่องมือบรรยาย ที่ดีมาก (เห็นปุ๊บรู้ว่าวันนั้นราคาถูกปฏิเสธที่ระดับไหน) แต่สิ่งที่ตำราเล่าต่อคือมันทำนายได้ ข้อหลังต้องพิสูจน์ วิธีทดสอบที่ตรงที่สุดคือสร้างโลกที่รู้แน่ว่าไม่มีอะไรทำนายได้ แล้วดูว่ารูปทรงยังโผล่หรือไม่ ผมจำลอง 400,000 วันของหุ้นที่เดินแบบสุ่มล้วนๆ (แต่ละวันมี 20 ก้าว ก้าวละ ±0.25% ความผันผวนรายวันราว 1.12% ไม่มี gap) แล้วตรวจว่าหลังเจอรูปทรงนั้น วันถัดไปเป็นแท่งขึ้นกี่ %:

ที่มา: การจำลองของบทเรียนนี้ (Python, numpy, seed 51, ดูกล่องโค้ด) ไม่ใช่ข้อมูลตลาดจริง · ผลนี้ไม่ได้พิสูจน์ว่าตลาดจริงไม่มีรูปแบบใดเลย พิสูจน์แค่ว่ารูปทรงเกิดขึ้นเองจากความสุ่มได้บ่อยมาก และการเห็นรูปทรงสวยๆ ไม่ใช่หลักฐาน · ผมไม่อ้างอัตราชนะของรูปทรงใดในตลาดจริง เพราะไม่ได้ตรวจแหล่งข้อมูลที่เชื่อถือได้ในรอบนี้

ใครอ้างว่ารูปทรงใดทำนายได้ ต้องแสดงสามอย่าง: อัตราขึ้นหลังเจอสูงกว่าฐานอย่างมีนัยสำคัญ ในข้อมูลที่ไม่ได้ใช้ตอนค้นหารูปแบบ และยังเหนือต้นทุนหลังหักค่าธรรมเนียมกับ spread (Day 22, 49) ไม่งั้นก็คือเหรียญที่ออกหัวครึ่งหนึ่ง แล้วจ่ายค่าธรรมเนียมทุกครั้งที่เล่น

ตัวอย่าง: เต้นเห็น "ค้อน" แล้วอยากซื้อ

สมมติเต้นเห็นหุ้น ก. ปิดเป็นค้อนที่ 50.50 หลังลงมาสามวัน (O 50.00 H 50.50 L 48.00 C 50.50) เลยซื้อ 50,000 บาทเพราะ "ราคาถูกปฏิเสธที่ 48" จากการจำลองข้างบน โอกาสที่วันถัดไปขึ้นยังราว 50% แต่ต้นทุนรอบซื้อ-ขายรอบหนึ่งตามสมมติฐาน Day 22 ราว 0.35% = 175 บาท ต่อ 50,000 บาท ถ้าทำแบบนี้ 100 รอบ ต้นทุนสะสมกัดผลตอบแทนไป 1 − (1 − 0.0035)100 = 29.57% (ตัวเลขเดียวกับ Day 48) นอกจากนี้ตัวเทียนแท่งเดียวไม่บอกช่องว่าง (gap) จากวันก่อนหน้า ซึ่งมักเป็นส่วนใหญ่ของการเคลื่อนไหวในวันที่ข่าวออก (ดูข้อ 3 ในควิซ)

ใช้แท่งเทียนอย่างไรให้ไม่หลอกตัวเอง

ใช้อ่านเรื่องราว: วันนั้นราคาไปถึงไหน ถูกปฏิเสธที่ไหน ปิดใกล้ขอบไหน (บทต่อไปจะใช้กับแนวรับแนวต้าน)

อย่าใช้เป็นสัญญาณซื้อขายเดี่ยวๆ: รูปทรงเดียวไม่ใช่หลักฐาน ต้องมีสมมติฐานและทดสอบย้อนหลังข้ามข้อมูลชุดอื่น

ระวัง pattern-seeking: สมองเราหารูปในความสุ่มเก่งมาก (Day 45) กราฟสุ่มหน้าตาเหมือนกราฟจริง

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
import numpy as np

# 1) สร้าง OHLC จาก tick
ticks = [50.00, 50.50, 51.25, 52.00, 51.00, 49.00, 49.75, 50.50, 51.00, 51.50]
O, H, L, C = ticks[0], max(ticks), min(ticks), ticks[-1]
rng, body = H - L, abs(C - O)
up, lo = H - max(O, C), min(O, C) - L
print(O, H, L, C, rng, body, body / rng, up, lo)
# 50.0 52.0 49.0 51.5 3.0 1.5 0.5 0.5 1.0

# 2) จำลองเดินสุ่ม 400,000 วัน แล้วเช็กหลังเจอ "ค้อน"
rs = np.random.default_rng(51)
D, T = 400_000, 20
rel = np.exp(np.concatenate([np.zeros((D, 1)),
        np.cumsum(rs.normal(0, 0.0025, (D, T)), axis=1)], axis=1))
cum = np.concatenate([[1.0], np.cumprod(rel[:, -1])[:-1]]) * 50   # ไม่มี gap
O, H, L, C = cum, cum * rel.max(1), cum * rel.min(1), cum * rel[:, -1]
r, b = H - L, abs(C - O)
lo, up = np.minimum(O, C) - L, H - np.maximum(O, C)
hammer = (lo >= 2 * b) & (up <= 0.1 * r) & (b > 0)
next_up = np.r_[C[1:] > O[1:], False]
hammer[-1] = False
print(hammer.sum(), next_up[hammer].mean())   # ~18,074 ครั้ง, ~0.499

ทดสอบความเข้าใจ

1. แท่งวันหนึ่ง O 50.00, H 52.00, L 49.00, C 51.50 คำนวณ range, ตัวเทียน, เงาบน, เงาล่าง, สัดส่วนตัวเทียน และ % เปลี่ยนจากเปิดถึงปิด

ดูเฉลย
range = 52 − 49 = 3.00 · ตัวเทียน = 51.50 − 50.00 = 1.50 (สัดส่วน 1.5/3 = 50%) · เงาบน = 52 − 51.5 = 0.50 · เงาล่าง = 50 − 49 = 1.00 · เปลี่ยน = 1.5/50 = +3.00% เป็นแท่งขึ้น

2. แท่ง O 50.00, H 50.50, L 48.00, C 50.50 เป็นรูปทรงอะไร และถ้าจำลองสุ่มแล้ววันถัดไปขึ้นราว 50% การซื้อเพราะรูปนี้ควรคิดอย่างไร

ดูเฉลย
ตัวเทียน 0.50 (20% ของ range 2.50) เงาล่าง 2.00 = 4 เท่าของตัว ≥ 2 เท่า และเงาบน 0 → ทรงค้อน · แต่รูปทรงนี้เกิดจากความสุ่มได้ ในการจำลองหลังค้อนวันถัดไปขึ้น 49.9% ไม่ต่างจากฐาน 50.1% จึงยังไม่มีหลักฐานว่าได้เปรียบ ขณะที่ต้นทุนจ่ายแน่นอนทุกรอบ

3. วันก่อนปิด 51.50 วันนี้ gap ลงเปิด 49.50 สูงสุด 50.00 ต่ำสุด 48.00 ปิด 48.50 ตัวเทียนวันนี้บอกว่าลงกี่ % แต่จริงๆ จากวันก่อนหน้าลงกี่ %

ดูเฉลย
ตัวเทียนวัดจากเปิดถึงปิด: (48.50 − 49.50)/49.50 = −2.02% · แต่ปิดต่อปิด (close-to-close): (48.50 − 51.50)/51.50 = −5.83% ส่วนต่าง 2.00 บาท (3.88%) หายไปในช่อง gap ที่ตัวเทียนไม่ได้วาด ดังนั้นแท่งเดียวมักประเมินการเคลื่อนไหวจริงต่ำไป

ทวน: Day 48 · ถ้าต้นทุนรอบละ 0.35% และเทรด 100 รอบ ต้นทุนสะสมกัดเงินทุนไปกี่ %

ดูเฉลย
1 − (1 − 0.0035)100 = 1 − 0.7043 = 29.57% ต้องหารูปแบบที่ชนะฐานมากกว่านี้ก่อนหักต้นทุน ถึงจะเริ่มมีกำไรจริง

ทวน: Day 45 · เพื่อนในกลุ่มแชตโพสต์กราฟว่า "ค้อนสามครั้งติด ขึ้นทุกครั้ง!" แล้วทุกคนเริ่มซื้อ นี่คืออคติอะไรบ้างที่ทำงานอยู่ และมีกฎเชิงระบบอะไรที่ช่วยกัน

ดูเฉลย
ตามฝูง (herding/FOMO) ทำให้ซื้อตามกลุ่ม · มั่นใจเกินเหตุ (overconfidence) และ อคติจากเหตุการณ์ล่าสุด (recency) ทำให้เอา 3 ครั้งมาเป็นกฎ ทั้งที่การจำลองบอกว่าครึ่งต่อครึ่งก็เกิดแบบนี้ได้ · กฎกัน: กฎ 48 ชั่วโมงก่อนซื้ออะไรที่ไม่อยู่ในแผน และ Investment Policy Statement ที่เขียนไว้ก่อน

สรุป 3 บรรทัด

1. แท่งเทียนบีบราคาทั้งช่วงเวลาเป็น OHLC: ตัวเทียนคือเปิดถึงปิด เงาคือสุดขอบที่ราคาไปถึงแล้วถูกดันกลับ ตัวเลขที่ใช้ได้จริงคือ range, ตัวเทียน, เงา และสัดส่วนตัวเทียนต่อ range

2. รูปทรงมีชื่อ (ค้อน โดจิ กลืนกิน) บรรยายวันนั้นได้ดี แต่ในโลกสุ่มล้วนๆ มันยังเกิดบ่อยและวันถัดไปขึ้นราว 50% เท่ากับฐาน จึงไม่ใช่หลักฐานการทำนาย

3. แท่งเดียวไม่มี gap ระหว่างวัน และสัญญาณใดๆ ต้องผ่านการทดสอบนอกตัวอย่างและเหนือต้นทุน ก่อนจะเอาเงินจริงไปเสี่ยง

พรุ่งนี้ Day 52 — Timeframe และการวิเคราะห์หลาย timeframe · แท่งเดียวกันในกราฟรายวันกับรายชั่วโมงเล่าคนละเรื่อง พรุ่งนี้ดูว่าเปลี่ยนมุมมองเวลาแล้วภาพเปลี่ยนอย่างไร และทำไมการเลือก timeframe ก็เป็นการตัดสินใจที่ต้องมีเหตุผล
