แนวรับแนวต้าน (support/resistance)

เส้นนอนที่นักวิเคราะห์ทางเทคนิควาดบนกราฟคือสิ่งที่ตลาดมีอยู่จริง หรือสมองเราวาดมันเอง วันนี้ทดสอบกับกราฟที่ทำจากเหรียญล้วน แล้วดูว่าควรใช้เส้นพวกนี้เพื่ออะไรจึงจะไม่หลอกตัวเอง

นิยาม: ระดับราคาที่ราคาเคยหยุด

แนวรับ (support) คือระดับราคาที่ราคาเคยลงมาถึงแล้วหยุดหรือเด้งกลับ แนวต้าน (resistance) คือระดับที่ราคาเคยขึ้นมาถึงแล้วหยุดหรือย่อตัว ตำราเสริมอีกสามข้อ ข้อแรก มักมองเป็นโซน (zone) ที่มีความกว้าง ไม่ใช่เส้นบางเฉียบ ข้อสอง เมื่อราคาทะลุแนวต้านขึ้นไปแล้ว แนวนั้นมักถูกเรียกว่ากลายเป็นแนวรับ (role reversal) ข้อสาม ตัวเลขกลม เช่น 50.00 มักถูกพูดถึงเป็นพิเศษ

เหตุผลที่ผู้เชื่อยกมามีสองข้อ: คำสั่งรอซื้อ-รอขายและ stop (Day 49-50) มักกองอยู่ที่ราคาเดิมๆ และมนุษย์ยึดติดราคาที่เคยเห็น (anchoring, Day 45) ทั้งสองข้อฟังขึ้น แต่ข้อควรถามคือ เส้นที่เราวาดจากอดีตช่วยทำนายอนาคตได้จริงหรือแค่บอกว่าราคาเคยแวะที่ไหน นิยามที่ใช้วันนี้: จุดกลับตัว (pivot) คือแท่งที่ราคาปิดสูงสุด (หรือต่ำสุด) เหนือเพื่อนบ้าน k แท่งทั้งสองข้าง (ใช้ k = 4) แล้วจับกลุ่มจุดกลับตัวที่ราคาอยู่ใกล้กันเป็น "แนว"

ทดลอง: หาแนวบนกราฟที่ทำจากเหรียญล้วน

กราฟด้านล่างคือหุ้น ก. (สมมติ) 120 แท่ง สร้างจากการเดินสุ่ม (random walk) ที่ขึ้นหรือลงแบบสุ่มทุกแท่ง ขนาดก้าวละประมาณ 0.60 บาท (σ รายแท่ง = 1.2% ของ 50 บาท) ไม่มีเรื่องราว ไม่มีข่าว ไม่มีใครตั้งคำสั่งรอที่ไหนเลย ปรับความกว้างของโซนและจำนวนครั้งขั้นต่ำที่ต้องโดน แล้วกดสุ่มกราฟใหม่:

ที่ค่าเริ่มต้น (โซน 1.0σ ต้องโดน 3 จุดขึ้นไป) ผมสุ่มกราฟแบบนี้ 20,000 ชุด พบว่า 92% มีอย่างน้อยหนึ่งแนว และเฉลี่ยชุดละ 2.26 แนว ทั้งที่สร้างจากเหรียญล้วน ลดโซนเหลือ 0.25σ ยังเจออยู่ 36% ของชุด และถ้าลดเกณฑ์เหลือ 2 จุด แทบทุกกราฟ (99.96%) มีแนว สาเหตุเชิงคณิตศาสตร์ไม่ลึก: การเดินสุ่มเคลื่อนที่ต่อเนื่อง จึงใช้เวลาวนอยู่ในช่วงราคาเดิมซ้ำๆ จุดกลับตัวหลายจุดจึง "บังเอิญ" อยู่ใกล้กัน ยิ่งกว้างโซน ยิ่งง่ายที่จะรวมจุดเข้าด้วยกัน

บทเรียนที่ได้ไม่ใช่ว่าแนวไม่มีอยู่จริงในตลาด แต่คือการเจอแนวบนกราฟอดีตไม่ใช่หลักฐานอะไรเลย เพราะกราฟเหรียญก็เจอ อีกข้อที่ซ่อนอยู่คือ ความกว้างโซนกับจำนวนครั้งขั้นต่ำเป็น "ปุ่มที่ปรับได้" ถ้าปรับจนเจอแนวที่ชอบ ก็เป็นปัญหาเดียวกับการเปรียบเทียบหลายครั้ง (multiple comparisons) ที่เห็นใน Day 52

ทดสอบที่คำถามเชิงเงิน: ราคาเด้งจากแนวจริงหรือไม่

แม้ในโลกที่เส้นไม่ทำนายอะไร แนวรับแนวต้านก็ยังมีประโยชน์เชิงปฏิบัติอยู่หนึ่งอย่าง: ใช้เป็นที่กำหนดจุดตัดขาดทุนและเงื่อนไขว่าสมมติฐานผิด ซึ่งต้องคิดเป็นตัวเลขตามหัวข้อต่อไป

ตัวอย่าง: ซื้อที่แนวรับ ตั้ง stop ใต้แนว ตั้งเป้าที่แนวต้าน

เต้นเห็นหุ้น ก. เด้งที่ 50.00 มาหลายครั้ง จึงซื้อที่ 50.00 วาง stop ใต้แนวที่ 49.50 ตั้งเป้าที่แนวต้าน 52.00 (กำไร 2.00 ขาดทุน 0.50 อัตราส่วน R:R = 4 : 1 ฟังดีมาก) ถ้าราคาเดินสุ่ม ไม่มีทิศ โอกาสแตะเป้าก่อน stop เป็นไปตามปัญหาผู้เล่นล้มละลาย (gambler's ruin): P(เป้าก่อน) = a ÷ (a + b) เมื่อ a = ระยะถึง stop, b = ระยะถึงเป้า คือ 0.50 ÷ 2.50 = 20% ค่าคาดหวังก่อนต้นทุนจึงเป็น 0.20 × 2.00 − 0.80 × 0.50 = 0 พอดี R:R ที่สูงถูกชดเชยด้วยอัตราชนะที่ต่ำพอดี ไม่มีใครได้เปรียบ จากนั้นต้นทุนซื้อ-ขายรอบละ 0.35% ของ 50 บาท = 0.175 บาทต่อหุ้น ทำให้ค่าคาดหวังเป็น −0.175 บาทต่อหุ้น และอัตราชนะที่เท่าทุนขยับจาก 20% เป็น (0.50 + 0.175) ÷ 2.50 = 27% ลองปรับระยะเอง:

ลองเลื่อนแล้วจะเห็นว่าไม่ว่าเลือก stop และเป้าหมายอย่างไร ค่าคาดหวังก่อนต้นทุนเป็นศูนย์เสมอ (เพราะสมมติว่าไม่มีทิศ) และหลังต้นทุนเท่ากับ −ต้นทุน เสมอ การย้าย stop ไม่ได้สร้างข้อได้เปรียบ มันแค่เปลี่ยนรูปร่างผลลัพธ์: stop แคบ = แพ้บ่อยครั้งละน้อย ชนะนานๆ ครั้งครั้งละมาก ซึ่งตรงกับตัวอย่าง stop 1% ใน Day 52 (ที่ σ รายวัน 0.60 บาท stop 0.50 บาท = 0.83σ มีโอกาสถูกแตะภายในวันเดียว 40.5%)

กฎใช้แนวรับแนวต้านให้ไม่หลอกตัวเอง

ใช้เป็นเงื่อนไขผิดพลาด ไม่ใช่คำทำนาย: "ถ้าหลุด 49.50 แปลว่าสมมติฐานผิด ออกทันที" ดีกว่า "ที่นี่ต้องเด้งแน่"

เขียนกฎวาดโซนล่วงหน้า: ค่า k ความกว้างโซน และจำนวนครั้งขั้นต่ำ กำหนดก่อนดูกราฟ ห้ามปรับให้เจอแนวที่อยากเห็น

คิดเป็น R:R และอัตราชนะที่เท่าทุนรวมต้นทุน: R:R ที่สวยบอกแค่ว่าชนะยาก ถ้าไม่มีหลักฐานเรื่องอัตราชนะจริง ตัวเลขนี้ไม่ใช่ข้อได้เปรียบ

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
import math
import numpy as np

Phi = lambda z: 0.5 * (1 + math.erf(z / math.sqrt(2)))

# 1) gambler's ruin: เดินสุ่มไม่มี drift แตะเป้า b ก่อน stop a
a, b, cost = 0.50, 2.00, 0.175          # cost = 0.35% ของ 50 บาท
p = a / (a + b)                          # 0.20
ev0 = p * b - (1 - p) * a                # 0.0
ev = p * (b - cost) - (1 - p) * (a + cost)  # -0.175
be = (a + cost) / (a + b)                # 0.27
print(p, ev0, ev, be)

# 2) โอกาสแตะ stop ภายใน 1 วัน (sigma รายวัน 0.60 บาท)
print(2 * Phi(-0.50 / 0.60))             # 0.4047

# 3) ทดสอบ "ราคาเด้งจากก้นเดิม" ในโลกสุ่ม
rng = np.random.default_rng(53)
x = np.cumsum(rng.normal(0, 1, 400_000))
k, tol, W = 5, 0.25, 3000
from numpy.lib.stride_tricks import sliding_window_view
w = sliding_window_view(x, 2 * k + 1)
piv = np.where(w[:, k] == w.min(axis=1))[0] + k   # ก้นที่ยืนยันแล้ว
ev_n = up_n = 0
for t in piv:
    L, s0 = x[t], t + k + 10
    if s0 >= len(x) - W - 1: break
    seg = x[s0:s0 + W]
    hit = np.where(seg <= L + tol)[0]
    if len(hit) == 0 or hit[0] == 0: continue
    j = hit[0]; p0 = seg[j]; fut = seg[j + 1:]
    u = np.where(fut >= p0 + 2)[0]; d = np.where(fut <= p0 - 2)[0]
    u = u[0] if len(u) else 10**9; d = d[0] if len(d) else 10**9
    if u == d == 10**9: continue
    ev_n += 1; up_n += (u < d)
print(ev_n, up_n / ev_n)                 # 16281, ~0.496

ทดสอบความเข้าใจ

1. ซื้อที่ 50.00 stop 49.50 เป้า 52.00 ต้นทุนรอบละ 0.175 บาทต่อหุ้น ถ้าราคาเดินสุ่มไม่มีทิศ โอกาสถึงเป้าก่อน stop เป็นเท่าไร และอัตราชนะที่เท่าทุนเป็นเท่าไร

ดูเฉลย
P(ถึงเป้าก่อน) = a ÷ (a + b) = 0.50 ÷ 2.50 = 20% · อัตราชนะที่เท่าทุน = (a + ต้นทุน) ÷ (a + b) = 0.675 ÷ 2.50 = 27% ตรวจ: 0.27 × (2.00 − 0.175) − 0.73 × (0.50 + 0.175) = 0.4928 − 0.4928 ≈ 0 อัตราชนะจริงของโลกสุ่มคือ 20% จึงต่ำกว่าจุดเท่าทุนอยู่ 7 จุด R:R 4 : 1 ไม่ได้ช่วยอะไรหากไม่มีหลักฐานว่าอัตราชนะสูงกว่า 27%

2. หุ้นมี σ รายวัน 0.60 บาท เต้นวาง stop ที่ 0.50 บาทใต้ราคาเข้า (ใต้แนวรับ) โอกาสที่ราคาแตะ stop ภายในวันเดียวคือเท่าไร (ใช้ 2Φ(−a ÷ σ)) และถ้าย้าย stop เป็น 1.50 บาท (2.5σ) เหลือเท่าไร

ดูเฉลย
a ÷ σ = 0.50 ÷ 0.60 = 0.833 ⇒ 2Φ(−0.833) = 2 × 0.2023 = 40.5% · a ÷ σ = 2.5 ⇒ 2Φ(−2.5) = 2 × 0.00621 = 1.24% แนวรับที่ "ดูใกล้" มักอยู่ในระยะที่เสียงรบกวนปกติของวันก็ถึง การเลือก stop จึงควรวัดเป็นหลาย σ ของช่วงที่ถือ (Day 52) ไม่ใช่ตามที่เส้นบนกราฟอยู่

3. กลยุทธ์ที่ R:R = 1.2 : 1 (กำไรต่อครั้ง 1.2 เท่าของความเสี่ยง) ต้องมีอัตราชนะเท่าไรจึงเท่าทุนก่อนต้นทุน และถ้าอัตราชนะจริง 45% ค่าคาดหวังต่อความเสี่ยง 1 หน่วยเป็นเท่าไร

ดูเฉลย
เท่าทุน: p × 1.2 = (1 − p) × 1 ⇒ p = 1 ÷ 2.2 = 45.45% · ที่ 45%: 0.45 × 1.2 − 0.55 × 1 = 0.54 − 0.55 = −0.01 หน่วยต่อครั้ง ติดลบนิดเดียวแต่ก่อนหักต้นทุนเสียอีก พอต้นทุนเข้ามา การเทรดถี่ๆ จะสะสมเป็นก้อนใหญ่ตามที่เห็นใน Day 48

ทวน: Day 45 · เกมโยนเหรียญ ออกหัวได้ 200 ออกก้อยเสีย 100 ค่าคาดหวังจริงเป็นเท่าไร และถ้าความเจ็บจากการเสียหนักกว่าความสุขจากการได้ λ = 2.25 เท่า ในใจจะรู้สึกเป็นเท่าไร

สรุป 3 บรรทัด

3. ใช้แนวเป็นจุดกำหนด stop และเงื่อนไขผิดพลาดที่คิดเป็นหลาย σ เขียนกฎวาดโซนล่วงหน้า และอย่าเชื่อ R:R โดยไม่มีหลักฐานเรื่องอัตราชนะ
