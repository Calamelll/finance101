Moving averages: SMA, EMA, golden/death cross

เส้นค่าเฉลี่ยเคลื่อนที่ (moving average, MA) คือเครื่องมือที่พบบ่อยที่สุดบนกราฟ เรียบกว่าราคา อ่านง่าย และมีสัญญาณ "ตัดกัน" ให้ แต่ความเรียบมีราคาที่ต้องจ่ายเป็นความล่าช้า (lag) วันนี้คำนวณทั้งสองแบบด้วยมือ แล้วนับว่าจุดตัดในกราฟเหรียญเกิดถี่แค่ไหนและกินค่าธรรมเนียมเท่าไร

SMA และ EMA คำนวณอย่างไร

ค่าเฉลี่ยเคลื่อนที่อย่างง่าย (simple moving average, SMA) ช่วง n แท่ง คือค่าเฉลี่ยของราคาปิด n แท่งล่าสุด ให้น้ำหนักเท่ากันทุกแท่ง (1/n) และแท่งที่เก่าเกิน n แท่งหลุดออกไปทันที: SMAt = (Pt + Pt−1 + … + Pt−n+1) ÷ n

ค่าเฉลี่ยเคลื่อนที่แบบถ่วงน้ำหนักเอกซ์โพเนนเชียล (exponential moving average, EMA) ใช้ราคาทุกแท่งในอดีต โดยน้ำหนักลดลงเป็นสัดส่วนคงที่ทุกแท่ง คำนวณแบบเรียกซ้ำ: EMAt = EMAt−1 + α (Pt − EMAt−1) โดย α = 2 ÷ (n + 1) ซึ่งเป็นแบบแผนที่นิยม ทำให้ EMA ช่วง n เทียบกับ SMA ช่วง n ได้ในเชิงอายุเฉลี่ยของข้อมูล น้ำหนักของแท่งที่เก่ากว่า i แท่งคือ α(1−α)i ที่ n = 10, α = 2/11 = 0.1818 น้ำหนักแท่งล่าสุด 0.1818 ถัดไป 0.1488, 0.1217, 0.0996, 0.0815 … รวม 10 แท่งแรก 86.6% อีก 13.4% กระจายอยู่กับข้อมูลที่เก่ากว่านั้น

ตัวอย่างด้วยมือ (เลขกลมๆ)

ราคาปิด 5 แท่งล่าสุดของหุ้น ก.: 50, 52, 51, 53, 54 ⇒ SMA5 = 260 ÷ 5 = 52.00

แท่งใหม่ปิด 56: SMA5 ใหม่ = (52 + 51 + 53 + 54 + 56) ÷ 5 = 266 ÷ 5 = 53.20 (แท่ง 50 หลุดออก ราคาเพิ่ม +2 จากค่าเดิม = (56 − 50) ÷ 5 = 1.20)

EMA5: α = 2/6 = 1/3 ถ้า EMA เดิม = 52.00 แล้วราคาปิด 56 ⇒ EMA ใหม่ = 52 + (56 − 52) ÷ 3 = 53.33 ขยับไปตามราคาใหม่แรงกว่า SMA เล็กน้อย

ความล่าช้า (lag): ราคาที่เรียบต้องจ่ายด้วยเวลา

MA ไม่ได้ทำนายอะไร มันคือ "ราคาย้อนหลังที่ถูกเกลี่ย" ลองวัดความล่าช้าด้วยการทดลองแบบขั้นบันได: ราคาเดินอยู่ที่ระดับหนึ่งแล้วกระโดดขึ้น 100% ของขนาดขั้นทันที (เช่น 50 → 60) และอยู่ที่ระดับใหม่ต่อ ถามว่า MA ตามขึ้นไปได้กี่ % ของขั้นหลังผ่านไป k แท่ง

  • SMA ช่วง n: หลัง k แท่ง ตามได้ k ÷ n (เส้นตรง) จนครบ 100% ที่ k = n
  • EMA ช่วง n: หลัง k แท่ง ตามได้ 1 − (1 − α)k เข้าใกล้ 100% เรื่อยๆ แต่ไม่ครบจริง

ที่น่าสนใจคือ ความล่าช้าเฉลี่ย (อายุเฉลี่ยของข้อมูลที่ใช้) ของทั้งสองแบบเท่ากัน = (n − 1) ÷ 2 แท่ง (n = 10 ⇒ 4.5 แท่ง สำหรับ SMA ตรวจจากค่าเฉลี่ยของอายุ 0, 1, …, 9; สำหรับ EMA คือ (1−α) ÷ α = (9/11) ÷ (2/11) = 4.5) ต่างกันที่รูปร่าง: EMA ตอบสนองเร็วกว่าในช่วงแรก (ครึ่งหนึ่งของขั้นภายใน 3.45 แท่ง เทียบกับ SMA 5 แท่ง) แต่ปลายหางยาวกว่า เพราะข้อมูลเก่ายังมีน้ำหนักเหลืออยู่ ลองปรับดู:

Golden cross และ death cross

เมื่อใช้ MA สองเส้น (เส้นเร็ว fast ช่วงสั้น และเส้นช้า slow ช่วงยาว) การตัดกันถูกตีความเป็นสัญญาณ: golden cross = เส้นเร็วตัดขึ้นเหนือเส้นช้า (มองเป็นขาขึ้น) และ death cross = เส้นเร็วตัดลงใต้เส้นช้า (มองเป็นขาลง) คู่ที่คนพูดถึงมากคือ 50 กับ 200 แท่ง (วัน)

ในทางคณิตศาสตร์ เส้นเร็วลบเส้นช้า คือ "โมเมนตัมแบบเกลี่ยแล้ว" ค่าเป็นบวกเมื่อราคาล่าสุดเฉลี่ยสูงกว่าราคาช่วงยาว ดังนั้นจุดตัดคือจุดที่ค่านั้นเปลี่ยนเครื่องหมาย ถ้าราคาเป็นเดินสุ่ม ค่านี้เปลี่ยนเครื่องหมายไปมาตามสัญญาณรบกวน ไม่ต้องมีเทรนด์ก็ตัดได้ ลองสุ่มกราฟ 160 แท่ง (หุ้น ก. สมมติ ผลตอบแทนรายแท่งสุ่มล้วน ไม่มี drift) เลือกคู่ช่วงและชนิด MA แล้วดูจุดตัด: วงกลมเขียว = golden, แดง = death กลยุทธ์ที่ใช้นับคือ "ถือเมื่อเส้นเร็วอยู่เหนือเส้นช้า ไม่ถือเมื่ออยู่ใต้" และคิดต้นทุน 0.35% ต่อหนึ่งรอบซื้อ-ขาย (ตัวเลขอ้างอิง Day 22 และ Day 48)

ความหมายของผลนี้

ในโลกสุ่ม จุดตัดเกิดได้เองตามสัญญาณรบกวน จำนวนจุดตัดและต้นทุนจึงคำนวณล่วงหน้าได้ โดยไม่ขึ้นกับว่ามีเทรนด์หรือไม่

กฎจะมีกำไรสุทธิได้ก็ต่อเมื่อราคามีความต่อเนื่องของทิศทาง (positive autocorrelation) มากพอที่จะเกินต้นทุน นี่คือสมมติฐานที่ต้องทดสอบด้วยข้อมูลนอกตัวอย่าง (out-of-sample) ไม่ใช่สิ่งที่ตำราหรือรูปกราฟสวยๆ พิสูจน์ให้

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
import numpy as np

def sma(x, n):
    c = np.cumsum(np.insert(x, 0, 0.0))
    out = np.full(len(x), np.nan)
    out[n - 1:] = (c[n:] - c[:-n]) / n
    return out

def ema(x, n):
    a = 2 / (n + 1)
    out = np.empty(len(x)); out[0] = x[0]
    for i in range(1, len(x)):
        out[i] = out[i - 1] + a * (x[i] - out[i - 1])
    return out

# ตัวอย่างด้วยมือ
p = [50, 52, 51, 53, 54]
print(sum(p) / 5, (52 + 51 + 53 + 54 + 56) / 5, 52 + (56 - 52) / 3)  # 52.0 53.2 53.33

# ตอบสนองต่อขั้นบันได n = 10, k = 5
n, k = 10, 5; a = 2 / (n + 1)
print(min(k / n, 1), 1 - (1 - a) ** k)       # 0.5  0.6334

# จำลองจุดตัด (random walk แบบ log, sigma = 1.2% ต่อแท่ง)
rng = np.random.default_rng(55)
price = 100 * np.exp(np.cumsum(rng.normal(0, 0.012, 400_000)))
f, s = sma(price, 50), sma(price, 200)
up = (f > s)[199:]
crosses = np.flatnonzero(up[1:] != up[:-1]).size
print(crosses / len(up) * 250)               # ~1.55 จุดตัดต่อ 250 แท่ง

สรุป 3 บรรทัด

1. SMA เฉลี่ยน้ำหนักเท่ากัน n แท่ง ส่วน EMA ใช้ α = 2/(n+1) ถ่วงน้ำหนักลดลงแบบเอกซ์โพเนนเชียล ทั้งคู่ล่าช้าเฉลี่ย (n−1)/2 แท่ง ต่างกันที่ EMA ตอบสนองเร็วช่วงแรก แต่มีหางยาว

2. Golden/death cross คือเส้นเร็วตัดเส้นช้า ในโลกสุ่มเกิดถี่ตามช่วงที่เลือก (5/20 ราว 16 จุดตัดต่อ 250 แท่ง, 50/200 ราว 1.6) และกินต้นทุน 2.75% กับ 0.27% ต่อปีตามลำดับ

3. กฎ MA มีกำไรสุทธิได้เมื่อราคามีทิศทางต่อเนื่องเกินต้นทุน ซึ่งต้องทดสอบนอกตัวอย่าง อย่าตัดสินจากกราฟที่ดูสวยย้อนหลัง
