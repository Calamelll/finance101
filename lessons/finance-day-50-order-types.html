ประเภทคำสั่ง: market, limit, stop, stop-limit

Day 49 เห็นแล้วว่ากระดานมีสองฝั่ง คำสั่งแต่ละแบบคือวิธีเลือกว่าจะ "จ่าย spread เพื่อความแน่นอน" หรือ "รอเพื่อราคาที่ดีกว่า" และแต่ละแบบมีจุดอ่อนของมันเอง

สองสิ่งที่คำสั่งทุกแบบต้องแลกกัน

ทุกคำสั่งซื้อขายตอบสองคำถามพร้อมกัน: ได้ราคาเท่าไร และ จะได้ซื้อขายจริงหรือไม่ ไม่มีคำสั่งไหนรับประกันทั้งสองอย่าง คำสั่งที่การันตีว่าจะได้ซื้อขาย (market) ไม่การันตีราคา ส่วนคำสั่งที่การันตีราคา (limit) ไม่การันตีว่าจะได้ซื้อขาย

คำสั่งทำงานอย่างไรการันตีไม่การันตี
Marketกินกระดานฝั่งตรงข้ามทันทีที่ราคาดีที่สุดเท่าที่มีได้ซื้อขายราคา
Limitซื้อไม่เกิน (หรือขายไม่ต่ำกว่า) ราคาที่ตั้ง ส่วนที่ยังไม่ match ไปรอบนกระดานราคาไม่แย่กว่าที่ตั้งได้ซื้อขายหรือไม่
Stopนอนรอ พอราคาถึงจุดกระตุ้น (trigger) จึงกลายเป็น marketถูกส่งเมื่อถึงจุดราคาที่ได้จริง
Stop-limitพอถึง trigger จึงกลายเป็น limit ที่ราคาที่ตั้งไว้ราคาไม่แย่กว่า limitว่าจะขายออกได้

Limit: ควบคุมราคา แลกกับความไม่แน่นอน

คำสั่ง limit ซื้อที่ราคาสูงกว่าหรือเท่ากับ best ask จะ match ทันทีเหมือน market (แต่ไม่ยอมจ่ายเกินราคาที่ตั้ง) ส่วนที่เหลือจะไปรอเป็น bid ในกระดาน ถ้าตั้งต่ำกว่า best ask จะไม่ได้อะไรเลยจนกว่ามีคนมาขายให้ที่ราคานั้น และต้องเข้าคิว: ตลาดจัดลำดับตามราคาก่อน แล้วตามเวลา (คนมาก่อนได้ก่อน) ลองกับกระดานเดียวกับ Day 49 ซื้อ 5,000 หุ้น แล้วเลื่อนราคา limit:

Stop และ stop-limit: คำสั่งที่นอนรอเงื่อนไข

คำสั่ง stop ไม่ได้อยู่ในกระดาน จนกว่าราคาซื้อขายถึง จุดกระตุ้น (trigger) ที่ใช้บ่อยคือ stop-loss ตั้งขายเมื่อราคาหลุดลงไปถึงระดับที่ยอมรับการขาดทุนได้ เมื่อถึงจุดนั้นมันกลายเป็นคำสั่งปกติ ถ้าเป็น stop (market) ก็ขายที่ราคาดีที่สุดที่มีตอนนั้น ถ้าเป็น stop-limit ก็ขายที่ราคา limit ขึ้นไปเท่านั้น

จุดอ่อนอยู่ที่ราคาไม่ได้ขยับต่อเนื่อง ลองดูสามสถานการณ์กับหุ้นที่ซื้อมา 1,000 หุ้น ที่ 50 บาท ตั้ง stop ที่ 48.00 (stop-limit ตั้ง limit ขาย 47.50):

บทเรียนคือ stop-loss ไม่ใช่เส้นตายราคา เป็นแค่เงื่อนไขให้ส่งคำสั่ง ถ้าราคาข้ามจุดนั้นไปเลย (gap) market stop จะขายที่ราคาแย่กว่าที่ตั้งมาก ส่วน stop-limit กันราคาแย่ได้ แต่แลกกับความเสี่ยงที่จะไม่ได้ขายเลยในวันที่ต้องการออกที่สุด

คำสั่งพิเศษของ SET และเรื่อง stop ในไทย

ตลาดหลักทรัพย์ไทยมีคำสั่งหลักๆ คือ limit, market และคำสั่งช่วงเปิด-ปิด: ATO (At-The-Open) ซื้อขายที่ราคาเปิด และ ATC (At-The-Close) ที่ราคาปิด สองแบบนี้ได้ลำดับก่อน limit ในการ match จึงเกือบแน่ว่าได้ แต่ไม่รู้ราคาล่วงหน้า เพราะราคาเปิด/ปิดมาจากการจับคู่ทั้งตลาด นอกจากนี้มี market-to-limit, IOC (ไม่ได้ทันทีก็ยกเลิก) และ FOK (ได้ครบทั้งก้อนหรือยกเลิกทั้งหมด) ส่วนคำสั่ง stop ไม่อยู่ในรายการคำสั่งของ SET โบรกเกอร์บางแห่งจึงทำเป็นคำสั่งเงื่อนไขในระบบของตัวเอง แล้วส่ง limit/market เข้าตลาดให้เมื่อราคาถึง ต้องเช็กกับโบรกที่ใช้ว่ามีหรือไม่ ทำงานตอนไหน และเสียค่าอะไร

ที่มา: Equities Trading — Order Types, ตลาดหลักทรัพย์แห่งประเทศไทย (classic.set.or.th/en/products/trading/equity/tradingsystem_p6.html) ตรวจอ่านเมื่อ 5 ต.ค. 2569 · หน้าเอกสารไม่ระบุวันปรับปรุงล่าสุด และไม่ได้กล่าวถึงคำสั่ง stop · คำสั่งเงื่อนไขของแต่ละโบรกแตกต่างกัน ต้องตรวจจากโบรกที่ใช้จริง

ตัวอย่าง: เต้นกับหุ้น ก. 50,000 บาท

ซื้อหุ้น ก. 1,000 หุ้น ที่ 50.00 ตั้ง stop-loss 48.00 ถ้าราคาไหลลงปกติ ขายได้ราว 47.75 ขาดทุน 2,250 บาท (4.5%) ไม่ใช่ 2,000 บาทที่คิดไว้ เพราะ spread ถ้าเช้าวันหนึ่ง gap ลงเปิด 45.00 ขาดทุน 5,000 บาท (10%) และขาดทุน 10% ต้องกำไร 1/0.9 − 1 = 11.11% ถึงจะคืนทุน (Day 43) ในทางกลับกัน ถ้าไม่ตั้งอะไรเลย แล้วไม่มีวินัยตัดขาดทุน ก็เสี่ยงโดนอคติ disposition effect (Day 45) เรื่องคำสั่งจึงไม่มีแบบถูกที่สุด มีแต่แบบที่เหมาะกับสิ่งที่ยอมแลก

เลือกคำสั่งตามสิ่งที่ยอมแลก

ต้องการได้แน่ ไม่สนราคาเป๊ะ (เช่น หุ้นสภาพคล่องสูง จำนวนน้อย): market หรือ ATC

ต้องการราคาดี ยอมรอหรือพลาดได้: limit (โดยเฉพาะหุ้นบาง ซึ่ง market จะเดินกระดานไกล ตาม Day 49)

อยากตัดขาดทุนอัตโนมัติ: เข้าใจก่อนว่า gap และกระดานบางทำให้ราคาออกจริงต่างจากที่ตั้ง และ stop ที่แคบเกินไปจะถูกสะบัดออกด้วยความผันผวนปกติ

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
asks = [(50.00, 3000), (50.25, 5000), (50.50, 8000), (50.75, 10000)]

def limit_buy(qty, limit):
    left, cost = qty, 0.0
    for price, size in asks:
        if price <= limit and left > 0:
            t = min(left, size); cost += t * price; left -= t
    filled = qty - left
    return filled, (cost / filled if filled else None), left

print(limit_buy(5000, 50.00))   # (3000, 50.0, 2000)
print(limit_buy(5000, 50.25))   # (5000, 50.1, 0)
print(limit_buy(5000, 49.75))   # (0, None, 5000)

# stop-loss: ขาย 1,000 หุ้น ซื้อมา 50 trigger 48
def stop_fill(next_bid, kind, limit=47.50):
    if kind == "market": return next_bid
    return next_bid if next_bid >= limit else None   # stop-limit

for bid in (47.75, 45.00):
    print(bid, stop_fill(bid, "market"), stop_fill(bid, "limit"))
# 47.75 47.75 47.75 | 45.0 45.0 None

ทดสอบความเข้าใจ

1. กระดานขาย 50.00 × 3,000 และ 50.25 × 5,000 ตั้ง limit ซื้อ 5,000 หุ้นที่ 50.00 เกิดอะไรขึ้น ถ้าเปลี่ยนเป็น 50.25 ได้ราคาเฉลี่ยเท่าไร

ดูเฉลย
ที่ 50.00: match ได้ 3,000 หุ้น ที่ 50.00 ส่วนอีก 2,000 หุ้นไปรอเป็น best bid ใหม่ที่ 50.00 · ที่ 50.25: ได้ครบ 5,000 หุ้น ราคาเฉลี่ย (3,000×50.00 + 2,000×50.25) ÷ 5,000 = 50.10 ไม่ใช่ 50.25 เพราะ limit คือเพดานราคา

2. ซื้อมา 50 บาท 1,000 หุ้น ตั้ง stop (market) ที่ 48.00 วันรุ่งขึ้นหุ้น gap ลงเปิดที่ bid 45.00 ขายได้ราคาไหน ขาดทุนกี่บาทกี่ % และถ้าเป็น stop-limit ที่ limit 47.50 เกิดอะไรขึ้น

ดูเฉลย
stop (market) ขายที่ 45.00 ขาดทุน 5 × 1,000 = 5,000 บาท (10%) ไม่ใช่ 4% ที่ตั้งใจ · stop-limit ที่ 47.50 ไม่ถูก match เพราะ bid 45.00 ต่ำกว่า limit ยังถือหุ้นอยู่และคำสั่งค้างรอ ถ้าราคาลงต่อก็ขาดทุนเพิ่ม

3. ตั้ง limit ซื้อ 5,000 หุ้นที่ 49.75 (best bid เดิม มีคิวรออยู่ข้างหน้า 4,000 หุ้น) ต่อมามีคนส่ง market ขาย 6,000 หุ้นเข้ามา ได้กี่หุ้น ที่ราคาเท่าไร

ดูเฉลย
คำสั่งขาย 6,000 หุ้นกิน 4,000 หุ้นของคิวข้างหน้าก่อน (ราคาเท่ากัน ใครมาก่อนได้ก่อน) เหลือ 2,000 หุ้นเป็นของเรา ได้ 2,000 หุ้น ที่ 49.75 ส่วนอีก 3,000 หุ้นยังรออยู่ · ได้ราคาต่ำกว่า mid 49.875 แต่ไม่รู้เลยว่าจะได้เมื่อไรหรือได้ครบไหม

ทวน: อคติ disposition effect ใน Day 45 คืออะไร และการตั้งกฎตัดขาดทุนล่วงหน้าช่วยเรื่องนี้ได้อย่างไร มีข้อจำกัดอะไรจากบทวันนี้

ดูเฉลย
disposition effect คือแนวโน้มขายหุ้นที่กำไรเร็วเกินไป แต่ถือหุ้นที่ขาดทุนไว้นานเกินไปเพราะไม่อยากรับรู้ผลขาดทุน · กฎล่วงหน้าที่เขียนไว้ตอนใจเย็น (เช่น stop-loss) ลดการตัดสินใจด้วยอารมณ์ในวันที่ราคาร่วง · ข้อจำกัดจากวันนี้: ราคาที่ขายได้จริงอาจต่ำกว่าที่ตั้ง (gap) หรือถูกสะบัดออกแล้วราคาเด้งกลับ (สถานการณ์ C)
ตอบผิดหรือลังเล? → ทบทวน Day 45: อคติทางพฤติกรรม (behavioral biases)

สรุป 3 บรรทัด

1. ทุกคำสั่งแลกกันระหว่างความแน่นอนของราคากับความแน่นอนที่จะได้ซื้อขาย: market ได้แน่แต่จ่าย spread และเดินกระดาน, limit คุมราคาแต่อาจไม่ได้ (และต้องเข้าคิว)

2. stop คือเงื่อนไขส่งคำสั่ง ไม่ใช่เส้นราคาที่รับประกัน: gap ทำให้ stop ขายที่ 45.00 แทน 48.00 และ stop-limit อาจไม่ได้ขายเลย

3. ใน SET มี limit, market, ATO, ATC และอื่นๆ แต่ไม่มี stop ในรายการคำสั่งของตลาด ต้องดูว่าโบรกของคุณจัดการคำสั่งเงื่อนไขอย่างไร

พรุ่งนี้ Day 51 — กราฟแท่งเทียน (candlestick) · เมื่อรู้แล้วว่าคำสั่งเข้าตลาดอย่างไร พรุ่งนี้จะเริ่มอ่านภาพราคาในอดีต: แท่งเทียนหนึ่งแท่งบอกอะไร (เปิด สูง ต่ำ ปิด) และอะไรที่มันบอกไม่ได้
