Momentum indicators: RSI และ Stochastic

ตัวชี้วัดโมเมนตัม (momentum indicator) บีบราคาให้อยู่ในกรอบ 0–100 เพื่อบอกว่า "แรงขึ้น" หรือ "แรงลง" ล่าสุดเป็นอย่างไร วันนี้คำนวณ RSI และ Stochastic ด้วยมือ ดูว่าคำว่า overbought/oversold แปลว่าอะไรกันแน่ แล้วนับในโลกสุ่มว่าสัญญาณเหล่านี้เกิดถี่แค่ไหน

RSI: เทียบแรงขึ้นกับแรงลง

ดัชนีกำลังสัมพัทธ์ (relative strength index, RSI) เสนอโดย J. Welles Wilder ในหนังสือปี 1978 ใช้ช่วงมาตรฐาน n = 14 แท่ง ไม่ได้ดูตำแหน่งราคา แต่ดูขนาดของแท่งขึ้นเทียบกับแท่งลง ขั้นตอนคือ แยกการเปลี่ยนแปลงราคาปิดแต่ละแท่งเป็น "กำไร" (gain, ถ้าขึ้น) หรือ "ขาดทุน" (loss, ถ้าลง) หาค่าเฉลี่ยของทั้งสองฝั่ง แล้วแปลงเป็น 0–100:

RS = AG ÷ AL   ⇒   RSI = 100 − 100 ÷ (1 + RS)
AG = ค่าเฉลี่ยแท่งขึ้น (average gain), AL = ค่าเฉลี่ยแท่งลง (average loss) · AL = 0 ⇒ RSI = 100 · RS = 1 ⇒ RSI = 50 · RSI 70 ⇔ RS = 7/3 ≈ 2.33 · RSI 30 ⇔ RS = 3/7 ≈ 0.43

หลังค่าเริ่มต้น Wilder ใช้การเฉลี่ยแบบเรียกซ้ำ AGt = (AGt−1 × (n−1) + gaint) ÷ n นั่นคือ EMA ที่ α = 1/n ซึ่งเทียบเท่า EMA แบบ α = 2/(N+1) ที่ช่วง N = 2n − 1 = 27 แท่งสำหรับ n = 14 (ตามบท Day 55 ความล่าช้าเฉลี่ยจึงนานกว่าที่เห็นจากเลข 14)

ตัวอย่างด้วยมือ (เลขกลมๆ)

ราคาปิด 15 แท่งของหุ้น ก.: 50, 51, 50, 52, 53, 52, 54, 55, 54, 56, 57, 56, 58, 59, 58 ⇒ 14 การเปลี่ยนแปลง ผลรวมแท่งขึ้น = 13 บาท ผลรวมแท่งลง = 5 บาท

AG = 13 ÷ 14 = 0.9286 · AL = 5 ÷ 14 = 0.3571 · RS = 13 ÷ 5 = 2.60 ⇒ RSI = 100 − 100 ÷ 3.60 = 72.22 (สูงกว่า 70)

แท่งถัดไปปิด 60 (+2): AG = (0.9286 × 13 + 2) ÷ 14 = 1.0051, AL = 0.3316 ⇒ RSI = 75.19 · ถ้าปิด 56 (−2): AG = 0.8622, AL = 0.4745 ⇒ RSI = 64.50

Stochastic: ราคาอยู่ตรงไหนของกรอบ

Stochastic oscillator ใช้แนวคิดต่างออกไป คือดูว่าราคาปิดล่าสุดอยู่ที่ตำแหน่งกี่ % ของกรอบสูง-ต่ำใน n แท่งล่าสุด:

%K = (C − Ln) ÷ (Hn − Ln) × 100   ·   %D = SMA3(%K)
C = ราคาปิดล่าสุด, Hn/Ln = จุดสูงสุด/ต่ำสุดใน n แท่ง · ปิดที่จุดสูงสุด ⇒ %K = 100 · ปิดที่จุดต่ำสุด ⇒ %K = 0 · เกณฑ์ที่นิยมคือ 80 และ 20

ตัวอย่าง: 14 แท่งล่าสุดสูงสุด 60 ต่ำสุด 50 ปิดที่ 58 ⇒ %K = (58 − 50) ÷ (60 − 50) × 100 = 80 ความต่างจาก RSI คือ Stochastic ไม่สนขนาดของแต่ละแท่ง สนแค่ "ปิดใกล้ขอบบนหรือขอบล่างของกรอบ" ในบทนี้ผมคำนวณจากราคาปิดอย่างเดียว (ใช้ high/low ของราคาปิดใน n แท่ง) เพื่อให้เทียบกันตรงๆ ในโลกจำลองที่ผมมีแต่ราคาปิด ทั้งสองตัวจึงวัดสิ่งที่ใกล้กัน: ในโลกสุ่ม สหสัมพันธ์ (correlation) ระหว่าง RSI14 กับ %K14 ≈ 0.83

Overbought / oversold แปลว่าอะไร

ตำราเรียก RSI > 70 ว่า "ซื้อมากเกินไป" (overbought) และ < 30 ว่า "ขายมากเกินไป" (oversold) ส่วน Stochastic ใช้ 80/20 แต่คำเหล่านี้เป็นแค่ชื่อของโซนบนมาตรวัด ไม่ใช่คำทำนาย คำถามที่ตรวจสอบได้คือ: (1) โซนนี้เกิดถี่แค่ไหน (2) พอเข้าโซนแล้ว ราคาถัดไปต่างจากปกติหรือไม่ ลองดูบนกราฟเดินสุ่ม แล้วลองเพิ่มแนวโน้ม (drift) ดูว่าโซนเปลี่ยนไปอย่างไร:

อ่านตารางได้ว่า (1) โซน RSI ที่เกิดได้เองโดยไม่ต้องมีเหตุผลใดคือราว 5% ของเวลา (2) %K ติด 80/20 ถึงราว 30% เพราะวัดตำแหน่งในกรอบ ไม่ใช่ขนาดแรง และอยู่ที่ขอบ 100 หรือ 0 พอดีราว 15% ของเวลา เกณฑ์ 80/20 ของ Stochastic จึงสัญญาณถี่กว่า RSI 70/30 มาก (3) ในโลกสุ่ม ราคาหลังเข้าโซนไม่ต่างจากฐานอย่างมีนัยสำคัญ ทั้งขึ้นและลง

ความหมายของผลนี้

RSI/Stochastic ไม่ได้บอก "ราคาถูก/แพง" มันคือฟังก์ชันของราคาที่ผ่านมา ตัวมันเองไม่ได้ให้ข้อมูลใหม่เรื่องอนาคต ถ้าราคาไม่มีรูปแบบ ค่าที่เกินโซนก็ไม่ได้พยากรณ์การกลับตัว

มีสองสมมติฐานตรงข้ามที่ต้องไม่ปนกัน: mean reversion (เกินโซนแล้วกลับ) กับ momentum/trend (เกินโซนแล้วไปต่อ เพราะ RSI สูงคือสัญญาณแรงขึ้น) ตัวชี้วัดตัวเดียวกันถูกใช้ได้ทั้งสองทาง การจะมีขอบได้ต้องทดสอบนอกตัวอย่าง (out-of-sample) หลังหักต้นทุน ไม่ใช่ดูจากกราฟที่ย้อนหลังแล้วดูสวย

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
import numpy as np
from numpy.lib.stride_tricks import sliding_window_view as sw

def wilder_rsi(p, n=14):
    d = np.diff(p)
    g = np.where(d > 0, d, 0.0); l = np.where(d < 0, -d, 0.0)
    ag = np.empty(len(d)); al = np.empty(len(d))
    ag[n - 1], al[n - 1] = g[:n].mean(), l[:n].mean()
    for i in range(n, len(d)):
        ag[i] = (ag[i - 1] * (n - 1) + g[i]) / n
        al[i] = (al[i - 1] * (n - 1) + l[i]) / n
    out = np.full(len(p), np.nan)
    out[n:] = 100 - 100 / (1 + ag[n - 1:] / np.where(al[n - 1:] == 0, 1e-12, al[n - 1:]))
    return out

def stoch_k(p, n=14):
    w = sw(p, n); hi, lo = w.max(1), w.min(1)
    k = np.full(len(p), np.nan)
    k[n - 1:] = (p[n - 1:] - lo) / np.where(hi == lo, 1e-12, hi - lo) * 100
    return k

# ตัวอย่างด้วยมือ
c = [50, 51, 50, 52, 53, 52, 54, 55, 54, 56, 57, 56, 58, 59, 58]
print(wilder_rsi(np.array(c, float))[-1])       # 72.22
print((58 - 50) / (60 - 50) * 100)               # 80.0

# จำลองเดินสุ่ม (sigma = 1.2% ต่อแท่ง)
rng = np.random.default_rng(56)
p = 100 * np.exp(np.cumsum(rng.normal(0, 0.012, 400_000)))
r = wilder_rsi(p)[14:]
print((r > 70).mean(), (r < 30).mean())          # ~0.048  ~0.046

ทดสอบความเข้าใจ

1. ใน 14 แท่งล่าสุด ผลรวมแท่งขึ้น = 21 บาท ผลรวมแท่งลง = 7 บาท จงหา AG, AL, RS และ RSI

ดูเฉลย
AG = 21 ÷ 14 = 1.50 · AL = 7 ÷ 14 = 0.50 · RS = 1.50 ÷ 0.50 = 3 ⇒ RSI = 100 − 100 ÷ 4 = 75 (อยู่ในโซนเหนือ 70) สังเกตว่า RSI ขึ้นกับอัตราส่วน 21 : 7 = 3 : 1 เท่านั้น

2. Stochastic %K: 14 แท่งล่าสุดสูงสุด 56 ต่ำสุด 50 ปิดที่ 53 ได้ %K เท่าไร และถ้ากรอบเป็น 58/48 ปิดที่ 55 ได้เท่าไร

ดูเฉลย
กรณีแรก (53 − 50) ÷ (56 − 50) × 100 = 50 · กรณีที่สอง (55 − 48) ÷ (58 − 48) × 100 = 70 %K บอกตำแหน่งในกรอบ ปิดกลางกรอบ = 50

3. จากตัวอย่าง RSI = 72.22 (AG = 0.9286, AL = 0.3571, n = 14) ถ้าแท่งถัดไปปิดลง 2 บาท RSI ใหม่เท่าไร (ใช้การเฉลี่ยแบบ Wilder) และเหตุใด RSI จึงไม่ตกต่ำกว่า 50 ในแท่งเดียว

ดูเฉลย
AG = 0.9286 × 13 ÷ 14 = 0.8622 · AL = (0.3571 × 13 + 2) ÷ 14 = 0.4745 ⇒ RS = 1.817 ⇒ RSI = 64.50 เพราะการเฉลี่ยแบบ Wilder ให้น้ำหนักแท่งใหม่เพียง 1/14 ข้อมูลเก่าถูกถือไว้ 13/14 RSI จึงขยับทีละน้อย

สรุป 3 บรรทัด

1. RSI = 100 − 100 ÷ (1 + AG/AL) วัดขนาดแท่งขึ้นเทียบแท่งลง ส่วน Stochastic %K วัดตำแหน่งปิดในกรอบสูง-ต่ำ n แท่ง ทั้งคู่ถูกบีบให้อยู่ในช่วง 0–100

2. โซน overbought/oversold คือชื่อของช่วงบนมาตรวัด ในโลกสุ่ม RSI เข้า 70/30 ราว 5% ของเวลา และราคา 10 แท่งถัดไปไม่ต่างจากฐานอย่างมีนัยสำคัญ

3. ตัวชี้วัดเดียวกันตีความได้ทั้ง mean reversion และ momentum (ตลาดมีเทรนด์ RSI อยู่ติดโซนบนได้นาน) ต้องทดสอบนอกตัวอย่างหลังหักต้นทุนก่อนเชื่อ
