Bollinger Bands และความผันผวน

Bollinger Bands คือ SMA ± k × ส่วนเบี่ยงเบนมาตรฐาน (standard deviation) ของราคา เปลี่ยนจากวัด "ทิศทาง" ใน Day 55–57 มาวัด "ความกว้างของการแกว่ง" วันนี้พิสูจน์ว่าแถบ 2σ ไม่ได้ครอบคลุม 95% อย่างที่หลายคนเข้าใจ และแถบแคบ (squeeze) ให้ข้อมูลได้ก็ต่อเมื่อความผันผวนมีการกระจุกตัว

สามเส้นและสองตัวชี้วัด

John Bollinger เสนอแถบนี้ในทศวรรษ 1980 ค่ามาตรฐานคือ (n = 20, k = 2) ใช้ราคาปิดย้อนหลัง n แท่ง:

Mid = SMAn  ·  Upper = Mid + k·σ  ·  Lower = Mid − k·σ
σ = ส่วนเบี่ยงเบนมาตรฐานของราคาปิด n แท่งล่าสุด (แบบประชากร หาร n) · หน่วยเป็นบาท ไม่ใช่ % ผลตอบแทน · %B และ BandWidth ใช้อ่านตำแหน่งและความกว้างของแถบ
%B = (Close − Lower) ÷ (Upper − Lower)  ·  BW = (Upper − Lower) ÷ Mid × 100 (%)
%B = 0 ที่เส้นล่าง, 0.5 ที่เส้นกลาง, 1 ที่เส้นบน · ค่าเกินช่วง 0–1 แปลว่าปิดนอกแถบ · BW คือความกว้างแถบเป็นสัดส่วนของราคา ใช้เทียบข้ามหุ้นได้ (เหมือน PPO ใน Day 57)

ตัวอย่างด้วยมือ

ราคาปิด 20 แท่งสลับ 48, 52, 48, 52, … (10 แท่งละค่า) ⇒ SMA = 50 · ผลรวมกำลังสองของส่วนเบี่ยงเบน = 20 × 2² = 80 ⇒ σ = √(80 ÷ 20) = 2

k = 2 ⇒ Upper = 50 + 4 = 54 · Lower = 50 − 4 = 46 ⇒ BW = (54 − 46) ÷ 50 = 16%

ถ้าแท่งถัดไปปิด 55 ⇒ %B = (55 − 46) ÷ 8 = 1.125 (ปิดเหนือเส้นบน) · ถ้าปิด 50 ⇒ %B = 0.5 พอดี

ลองลด k ลงเหลือ 1: แถบแคบลง ราคาเดิมกลายเป็น "นอกแถบ" ทันที ทั้งที่ราคาไม่ได้เปลี่ยน นี่คือข้อเตือนข้อแรก "ปิดนอกแถบ" เป็นคำที่ขึ้นกับ k ที่เลือก ไม่ใช่สมบัติของตลาด

แถบ 2σ ครอบคลุมกี่ %?

ถ้าราคาปิดแต่ละแท่งเป็นตัวแปรสุ่มปกติที่เป็นอิสระต่อกัน k = 2 จะครอบคลุม 95.45% และนอกแถบแค่ 4.55% แต่ราคาไม่ใช่ตัวแปรอิสระ มันเป็นผลสะสมของผลตอบแทน (Day 52) ภายในหน้าต่าง 20 แท่ง ราคาแกว่งตามแนวโน้มเส้นทางเดียวกัน และ SMA ที่อยู่กลางหน้าต่างล้าหลังจุดปลายอยู่เสมอ ผลคือแท่งล่าสุดมักอยู่ไกลจาก SMA เกิน σ ที่คำนวณจากหน้าต่างเดียวกัน

เชิงทฤษฎี เมื่อผลตอบแทนต่อแท่งมี σr และราคาอยู่ราว P ค่า RMS ของ σ ในหน้าต่าง n แท่งคือ:

σband ≈ σr · P · √((n² − 1) ÷ (6n))  ⇒  n = 20: 1.8235 · σr · P
เส้นทางเดินสุ่ม n จุดมี E[ความแปรปรวนในหน้าต่าง] = σ²(n²−1)/(6n) · ตรวจด้วยเดินสุ่ม 2,000,000 จุด (n = 20) ได้ RMS 1.8231 เทียบสูตร 1.8235 · ใช้ประมาณเท่านั้น (ใช้ RMS ไม่ใช่ค่าเฉลี่ยของ σ ซึ่งต่ำกว่าเล็กน้อย)

ตัวอย่างบาท: หุ้นราคา 50 บาท σ ต่อวัน 1.2% ⇒ σband ≈ 1.8235 × 0.012 × 50 = 1.094 บาท ⇒ ครึ่งความกว้างแถบ k = 2 ≈ 2.19 บาท (≈ 4.4% ของราคา) และ BW ≈ 4 × 1.8235 × 1.2% = 8.75% ความผันผวนต่อวันที่ Day 43 วัดเป็นเปอร์เซ็นต์ จึงแปลงเป็นความกว้างแถบเป็นบาทได้โดยตรงด้วยสูตรนี้

อ่านตารางได้สามข้อ (1) ปิดนอกแถบ 2σ จริงราว 12% ไม่ใช่ 4.55% มากกว่าที่คิดราว 2.6 เท่า (11.84 ÷ 4.55 = 2.60) เพราะราคาเป็นเส้นทางสะสมไม่ใช่ตัวอย่างอิสระ การ "ทะลุแถบ" จึงเป็นเหตุการณ์ธรรมดาที่เกิดราว 15 ครั้งต่อ 250 แท่ง (2) ราคา 10 แท่งหลังทะลุไม่ต่างจากฐานในทั้งสองโลก (3) แถบแคบ (squeeze) ให้ข้อมูลเฉพาะเรื่อง "ขนาดของการแกว่งครั้งถัดไป" และเฉพาะเมื่อ σ กระจุกตัว ในโลก iid อัตราส่วนเป็น 1.0 พอดี แต่ในโลก GARCH หลังบีบ σ ถัดไปต่ำกว่าเฉลี่ย 22% และหลังกว้างสุดสูงกว่า 41% ซึ่งเป็นสิ่งที่ตลาดจริงมักแสดงให้เห็น แต่ไม่ได้บอกทิศทางเลย

ความหมายของผลนี้

Bollinger Bands เป็นเครื่องมือวัดความผันผวนมากกว่าเครื่องมือทำนายทิศทาง ใช้ได้ดีในการตั้ง stop ตามความกว้างแถบและกำหนดขนาดสถานะ (position sizing) ให้เสี่ยงเท่ากันเมื่อ σ เปลี่ยน

กฎ "ทะลุเส้นล่างแล้วซื้อ" ในโลกสุ่มต้องจ่ายต้นทุนราว 15.34 ครั้ง × 0.35% = 5.37% ต่อปี ถ้าทุกการทะลุเป็นหนึ่งรอบเทรด โดยที่ราคาหลังทะลุไม่ต่างจากฐาน

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
import numpy as np

def bands(p, n=20, k=2):
    c, c2 = np.cumsum(np.insert(p, 0, 0)), np.cumsum(np.insert(p * p, 0, 0))
    mid = (c[n:] - c[:-n]) / n
    sd = np.sqrt(np.maximum((c2[n:] - c2[:-n]) / n - mid**2, 0))
    return mid, mid - k * sd, mid + k * sd

# ตัวอย่างมือ: 48/52 สลับกัน 20 แท่ง
x = np.array([48, 52] * 10, float)
mid, lo, up = bands(x)
print(mid[-1], lo[-1], up[-1])             # 50  46  54
print((55 - lo[-1]) / (up[-1] - lo[-1]))   # %B = 1.125
print((up[-1] - lo[-1]) / mid[-1] * 100)   # BW = 16.0

# จำลองเดินสุ่ม (sigma = 1.2% ต่อแท่ง)
rng = np.random.default_rng(58)
p = 100 * np.exp(np.cumsum(rng.normal(0, 0.012, 400_000)))
mid, lo, up = bands(p)
P = p[19:]
print(((P > up) | (P < lo)).mean())      # ~0.118 (ไม่ใช่ 0.0455)

# ทฤษฎี: sigma ในหน้าต่าง
n = 20
print(np.sqrt((n * n - 1) / (6 * n)))      # 1.8235

ทดสอบความเข้าใจ

1. SMA20 = 80 บาท σ = 4 บาท k = 2 จงหาเส้นบน เส้นล่าง BandWidth และ %B ถ้าราคาปิด 70 บาท

ดูเฉลย
Upper = 80 + 8 = 88 · Lower = 80 − 8 = 72 · BW = 16 ÷ 80 × 100 = 20% · %B = (70 − 72) ÷ 16 = −0.125 (ติดลบ = ปิดใต้เส้นล่าง) ตัวเลขนอกช่วง 0–1 ไม่ใช่ข้อผิดพลาด แต่คือสัญญาณว่าอยู่นอกแถบ

2. หุ้นราคา 80 บาท σ ผลตอบแทนต่อวัน 1.5% ประมาณครึ่งความกว้างแถบ (20, 2) เป็นกี่บาท และ BW เท่าไร

ดูเฉลย
σband ≈ 1.8235 × 0.015 × 80 = 2.188 บาท ⇒ ครึ่งความกว้าง = 2 × 2.188 ≈ 4.38 บาท (5.47% ของราคา) · BW ≈ 4 × 1.8235 × 1.5 = 10.94% เป็นค่าประมาณจาก RMS ของ σ ในหน้าต่าง

3. จากการจำลอง ปิดนอกแถบ (20, 2) จริง 11.84% ถ้ามี 1,000 แท่ง คาดว่านอกแถบกี่แท่ง เทียบกับที่ทฤษฎีปกติบอก และต่างกันกี่เท่า

ดูเฉลย
จริง ≈ 118 แท่ง · ทฤษฎีปกติ 4.55% ⇒ ≈ 46 แท่ง ⇒ ต่างกัน 11.84 ÷ 4.55 = 2.60 เท่า สาเหตุคือราคาในหน้าต่างเป็นเส้นทางสะสมที่ล้าหลัง SMA ไม่ใช่ตัวอย่างอิสระจากการแจกแจงปกติ

สรุป 3 บรรทัด

1. Bollinger = SMAn ± k·σ ของราคา, %B = ตำแหน่งในแถบ (0 ล่าง, 1 บน), BW = ความกว้างเป็น % ของราคา ในเดินสุ่ม σband ≈ σr·P·√((n²−1)/(6n)) ซึ่ง n = 20 ได้ 1.8235 σr P

2. แถบ 2σ ไม่ใช่ 95%: ในโลกจำลองปิดนอกแถบราว 12% (2.6 เท่าของ 4.55%) การทะลุแถบจึงเป็นเรื่องปกติ และราคาหลังทะลุไม่ต่างจากฐาน

3. squeeze บอกขนาดการแกว่งถัดไปได้เมื่อ σ กระจุกตัว (GARCH: 0.78 เท่าหลังบีบ, 1.41 เท่าหลังกว้าง) แต่ไม่บอกทิศ ใช้วัดความเสี่ยงและตั้ง stop ได้ แต่กฎซื้อ-ขายเมื่อทะลุเสียต้นทุนราว 5.37% ต่อปี
