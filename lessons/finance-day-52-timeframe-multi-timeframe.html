Timeframe และการวิเคราะห์หลาย timeframe

กราฟเดียวกัน ข้อมูลเดียวกัน แต่เปลี่ยนความยาวของแท่งแล้วเรื่องที่เล่าเปลี่ยนไปทั้งเรื่อง วันนี้เรียนว่าทำไม และใช้หลาย timeframe อย่างไรโดยไม่หลอกตัวเอง

เปลี่ยน timeframe คือรวมแท่ง ไม่ใช่เพิ่มข้อมูล

Timeframe คือความยาวเวลาของแท่งหนึ่งแท่ง (1 นาที 15 นาที 1 ชั่วโมง 1 วัน 1 สัปดาห์) แท่งใหญ่สร้างจากแท่งเล็กด้วยกฎตายตัว: Open = Open ของแท่งแรกในกลุ่ม · Close = Close ของแท่งสุดท้าย · High = High สูงสุดของทั้งกลุ่ม · Low = Low ต่ำสุดของทั้งกลุ่ม ตัวเทียนไม่ใช่ค่าเฉลี่ย ดังนั้นแท่งรายชั่วโมงที่ขึ้น-ลง-ลง รวมกันเป็นแท่ง 3 ชั่วโมงที่ขึ้นได้ ถ้าราคาปิดสุดท้ายสูงกว่าราคาเปิดแรก ด้านล่างคือหุ้น ก. สังเกตว่าราคาเปิดแรก 50.00 และปิดสุดท้าย 51.97 (+3.94%) เหมือนกันทุกมุมมอง เปลี่ยนแค่ความละเอียด กราฟละเอียดเห็นจังหวะสลับขึ้น-ลงจนแยกทิศยาก กราฟหยาบดูเป็นเส้นทางชัดขึ้น แต่ระวัง: 4 แท่งเป็นหลักฐานน้อยมาก ภาพที่ "ชัด" ส่วนหนึ่งมาจากการที่เรามีจุดข้อมูลน้อยลง ไม่ได้แปลว่ามันแม่นกว่า

ทำไมกราฟใหญ่ดูเป็นเทรนด์ และกราฟเล็กดูเป็นเสียงรบกวน

ถ้าผลตอบแทนแต่ละช่วงเป็นอิสระต่อกัน (สมมติฐานประมาณการที่ใช้บ่อย) แนวโน้มสะสมเป็นเส้นตรงตามเวลา แต่เสียงรบกวนสะสมตามรากที่สอง เพราะความแปรปรวน (variance) บวกกันได้ ส่วนค่าเบี่ยงเบนมาตรฐาน (standard deviation, σ) บวกกันไม่ได้:

σT = σ1 × √T  ·  μT = μ1 × T
P(แท่งขึ้น) ≈ Φ( (μ1 ÷ σ1) × √T )
Φ = ฟังก์ชันการแจกแจงสะสมของโค้งปกติ · T = จำนวนช่วงฐานในแท่ง · อัตราส่วนสัญญาณต่อเสียงรบกวน (signal-to-noise) โตตาม √T ยิ่งแท่งยาว ทิศทางยิ่งชนะเสียงรบกวน

ลองใส่สมมติฐานของคุณเอง (ค่าเริ่มต้น: ตลาดโตปีละ 8% ผันผวนรายวัน 1.2% ต้นทุนต่อรอบ 0.35% ตามสมมติฐาน Day 22 stop-loss ห่าง 1% โดยปีหนึ่งมี 250 วันทำการ และวันหนึ่งมี 240 นาทีเพื่อให้เลขกลม ทั้งหมดเป็นสมมติฐานเพื่อการสอน ไม่ใช่สถิติตลาด):

timeframeσ ของแท่งโอกาสแท่งขึ้นต้นทุน ÷ σโอกาสแตะ stop*

* โอกาสที่ราคาแตะระดับ stop ภายในช่วงเวลาของแท่งนั้น = 2Φ(−a ÷ σT) (หลักการสะท้อน, reflection principle) สมมติ drift = 0 และตามราคาต่อเนื่อง จึงเป็นค่าประมาณคร่าวๆ

อ่านตารางตามค่าเริ่มต้นแล้วจะเห็นสามเรื่อง ข้อแรก แท่ง 1 นาทีขึ้นแค่ 50.07% เกือบโยนเหรียญ ส่วนแท่งรายปีขึ้น 66.34% ทิศทางเดียวกันแต่ช่วงยาวกว่าจึงเด่นขึ้น ข้อสอง ต้นทุน ÷ σ บอกว่าค่าธรรมเนียมรอบเดียวใหญ่เท่าไรเมื่อเทียบกับการเคลื่อนไหวปกติของแท่ง: ที่ 1 นาทีคือ 4.52 เท่า ที่ 1 วันคือ 0.29 เท่า ที่ 1 เดือนเหลือ 0.06 เท่า (ต่อกับ Day 48 และ 49: ยิ่งเทรดถี่ ต้นทุนยิ่งกลืนทุกอย่าง) ข้อสาม ระยะ stop ต้องวัดเป็น "กี่ σ ของช่วงที่ถือ" ไม่ใช่เป็นกี่ % ที่รู้สึกสบายใจ ดูหัวข้อตัวอย่างต่อไป

การวิเคราะห์หลาย timeframe: บนลงล่าง (top-down)

แนวคิดมาตรฐานที่ตำราสอนคือใช้ timeframe หลายระดับทำคนละหน้าที่ โดยเว้นระยะแต่ละระดับราว 4–6 เท่า (เช่น รายสัปดาห์ → รายวัน → รายชั่วโมง) ไม่มีตัวเลขวิเศษ เป็นแค่ธรรมเนียมที่ทำให้แต่ละระดับให้ข้อมูลต่างกันพอสมควร:

  • 1) ใหญ่สุด: บริบทและทิศราคาอยู่ในช่วงขึ้น ลง หรือแกว่งข้าง ใช้ตัดสินว่าจะถือยาวหรือไม่ และกำหนดว่าจะ "ไม่สู้" กับทิศใหญ่
  • 2) กลาง: โครงสร้างและเหตุผลของการเข้าระดับราคาที่สำคัญ (บทหน้าเรื่องแนวรับแนวต้าน) และเงื่อนไขที่ทำให้สมมติฐานผิด
  • 3) เล็กสุด: จังหวะเข้าและจุดตัดขาดทุนใช้เลือกราคาเข้าให้ดีขึ้นเล็กน้อย ไม่ใช้เป็นเหตุผลหลักในการเข้า

เหตุผลเชิงตรรกะดี แต่ก่อนเชื่อว่า "ทุก timeframe ชี้ทางเดียวกัน = สัญญาณแรง" ให้ทดสอบกับโลกที่รู้แน่ว่าไม่มีอะไรทำนายได้ ผมจำลองผลตอบแทนแท่งฐานแบบสุ่มล้วน 1,000,000 แท่ง (ไม่มี drift) แล้วนิยาม "timeframe สูงขึ้น" = 16 แท่งล่าสุดรวมกันเป็นบวก และ "timeframe ต่ำขึ้น" = 4 แท่งล่าสุดเป็นบวก จากนั้นดูแท่งถัดไป:

เงื่อนไขที่ตรวจเจอเกิดบ่อยแค่ไหนแท่งถัดไปขึ้น
ทุกกรณี (ฐาน)100%50.0%
สูงขึ้น และ ต่ำขึ้น (ชี้ทางเดียวกัน)33.4%50.0%
สูงขึ้น แต่ ต่ำลง (ย่อในขาขึ้น)16.7%49.8%

ที่มา: การจำลองของบทเรียนนี้ (Python, numpy, seed 52, 999,984 จุดตัดสินใจ ดูกล่องโค้ด) ไม่ใช่ข้อมูลตลาดจริง · ตัวเลขนี้พิสูจน์แค่ว่าการเรียงกันของ timeframe เกิดขึ้นเองจากความสุ่มได้บ่อย ไม่ได้พิสูจน์ว่าตลาดจริงไม่มีโมเมนตัมเลย (Day 55-56 จะทดสอบเครื่องมือที่อิงโมเมนตัม) · ผมไม่อ้างอัตราชนะของกลยุทธ์หลาย timeframe ในตลาดจริง เพราะรอบนี้ไม่ได้ตรวจแหล่งข้อมูลที่เชื่อถือได้

สังเกตว่าสองระดับ "ชี้ทางเดียวกัน" 33.4% ของเวลา มากกว่า 25% ที่ควรเป็นถ้าเป็นอิสระต่อกัน เพราะแท่งเล็กซ้อนอยู่ในแท่งใหญ่ ไม่ใช่หลักฐานสองชิ้นแยกกัน มันคือหลักฐานชิ้นเดียวมองสองระยะ อีกข้อที่ต้องระวังคือ ยิ่งมีหลาย timeframe ยิ่งมีวิธีตีความเยอะ ถ้าอยากเห็นขาขึ้น เกือบเสมอจะมีสักระดับที่ดูขึ้นให้หยิบมาใช้ได้ (ปัญหาการเปรียบเทียบหลายครั้ง หรือ multiple comparisons) วิธีกันคือเขียนกฎล่วงหน้าว่าใช้ timeframe ไหนทำหน้าที่อะไร ก่อนเห็นกราฟ

ตัวอย่าง: stop-loss 1% ที่ถูกเลือกจากกราฟผิดระดับ

เต้นซื้อหุ้น ก. 50,000 บาท ตั้ง stop-loss ห่าง 1% (500 บาท) เพราะ "รู้สึกว่าไม่เจ็บเกินไป" (Day 50: คำสั่ง stop) แล้วถือไว้ราว 1 วัน ที่ σ รายวัน 1.2% ระยะ 1% คือแค่ 0.83σ โอกาสที่ราคาแตะ stop ระหว่างวันตามสูตรสะท้อน = 2Φ(−1/1.2) = 40.5% แม้ไม่มีเหตุผลทางธุรกิจที่ทำให้สมมติฐานผิดเลย ถ้ากว้างเป็น 3% (2.5σ) เหลือแค่ 1.2% แต่เมื่อถูกแตะจะขาดทุน 1,500 บาทต่อครั้ง ส่วนการดูกราฟ 1 นาทีแล้วเห็นว่า "1% ห่างตั้ง 13 เท่าของแท่ง" ก็หลอกให้รู้สึกปลอดภัยเกินจริง เพราะมองผิดระดับกับช่วงที่ถือจริง คำถามที่ถูกคือ ช่วงที่ฉันถือคือเท่าไร และ σ ของช่วงนั้นเท่าไร แล้วค่อยวางระยะเป็นหลาย σ ตามเงื่อนไขที่ทำให้สมมติฐานผิดจริง

กฎใช้ timeframe ให้ไม่หลอกตัวเอง

เลือก timeframe จากช่วงที่ถือจริง: ถือเป็นวัน ใช้ σ รายวันวัดระยะ stop และเป้าหมาย ไม่ใช้ σ ของแท่งนาที

เขียนหน้าที่ของแต่ละระดับล่วงหน้า: ใหญ่ = ทิศ กลาง = เหตุผล เล็ก = จังหวะ ห้ามสลับระดับย้อนหลังเพื่อให้เรื่องลงตัว

เช็กต้นทุน ÷ σ ก่อนลงมือ: ยิ่งแท่งเล็ก ต้นทุนยิ่งใหญ่กว่าการเคลื่อนไหวที่ต้องอาศัยทำกำไร ระดับที่ต้นทุนเกิน σ หลายเท่าไม่ใช่สนามที่คนทั่วไปชนะ

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
import math
import numpy as np

Phi = lambda z: 0.5 * (1 + math.erf(z / math.sqrt(2)))

# 1) รวมแท่ง: O แรก, H สูงสุด, L ต่ำสุด, C สุดท้าย
def agg(bars, k):
    out = []
    for i in range(0, len(bars), k):
        g = bars[i:i + k]
        out.append([g[0][0], max(x[1] for x in g), min(x[2] for x in g), g[-1][3]])
    return out

h = [[50.00, 50.80, 49.70, 50.60], [50.60, 51.20, 50.40, 50.50], [50.50, 50.70, 49.90, 50.10]]
print(agg(h, 3))   # [[50.0, 51.2, 49.7, 50.1]]

# 2) สเกล sqrt(T)
mu, sd, c, a = 0.08 / 250, 0.012, 0.0035, 0.01
for name, T in [("1min", 1 / 240), ("1day", 1), ("1week", 5), ("1month", 21), ("1year", 250)]:
    s = sd * math.sqrt(T)
    print(name, f"sigma={s:.4%}", f"P(up)={Phi(mu * T / s):.2%}",
          f"cost/sigma={c / s:.2f}", f"touch={min(1, 2 * Phi(-a / s)):.2%}")
# 1min  sigma=0.0775% P(up)=50.07% cost/sigma=4.52 touch=0.00%
# 1day  sigma=1.2000% P(up)=51.06% cost/sigma=0.29 touch=40.47%
# 1year sigma=18.9737% P(up)=66.34% cost/sigma=0.02 touch=95.80%

# 3) จำลอง: timeframe สูง/ต่ำ ชี้ทางเดียวกันทำนายอะไรได้ไหม (โลกสุ่ม)
rs = np.random.default_rng(52)
r = rs.normal(0, 1, 1_000_000)
cs = np.concatenate([[0], np.cumsum(r)])
t = np.arange(16, len(r))
hi, lo = (cs[t] - cs[t - 16]) > 0, (cs[t] - cs[t - 4]) > 0
nxt = r[t] > 0
print((hi & lo).mean(), nxt[hi & lo].mean())   # ~0.334, ~0.500

1. แท่งรายชั่วโมงสามแท่งติดกัน: (O 50.00 H 50.80 L 49.70 C 50.60), (O 50.60 H 51.20 L 50.40 C 50.50), (O 50.50 H 50.70 L 49.90 C 50.10) รวมเป็นแท่ง 3 ชั่วโมงได้ OHLC เท่าไร และแท่งนี้ขึ้นหรือลง ทั้งที่แท่งชั่วโมงสองในสามแท่งเป็นแท่งลง

2. σ รายวัน 0.9% ถ้าผลตอบแทนรายวันเป็นอิสระต่อกัน σ ของ 16 วันทำการเป็นเท่าไร และต้องรวมกี่วันถึงได้ σ เป็นสองเท่าของรายวัน

ดูเฉลย
σ16 = 0.9% × √16 = 0.9 × 4 = 3.60% (ไม่ใช่ 14.4% ที่ได้จากการคูณ 16) · σ เป็น 2 เท่า ⇒ √T = 2 ⇒ T = 4 วัน เสียงรบกวนโตช้ากว่าเวลา แต่ drift โตตามเวลาเต็มๆ จึงทำให้กราฟยาวดูเป็นเทรนด์

3. ตลาดมี drift 12% ต่อปี (0.048% ต่อวัน ถ้า 250 วัน) σ รายวัน 1.5% โอกาสที่แท่งรายวันขึ้นกับแท่งรายเดือน (21 วัน) ขึ้น เป็นเท่าไร (ใช้ P ≈ Φ(μ√T ÷ σ)) และทำไมค่าไม่เท่ากัน

ดูเฉลย
รายวัน: z = 0.048 ÷ 1.5 = 0.032 ⇒ Φ(0.032) = 51.28% · รายเดือน: z = 0.032 × √21 = 0.1466 ⇒ Φ(0.1466) = 55.83% · drift โตตาม T แต่เสียงรบกวนโตตาม √T อัตราส่วนสัญญาณต่อเสียงรบกวนจึงโตตาม √T แท่งยาวขึ้นบ่อยกว่า แต่ยังห่างจาก "แน่นอน" มาก ที่ระดับรายเดือนยังลงเกือบครึ่งหนึ่ง (44.17%)

สรุป 3 บรรทัด

1. เปลี่ยน timeframe คือรวมแท่ง (O แรก, H สูงสุด, L ต่ำสุด, C สุดท้าย) ไม่ได้เพิ่มข้อมูล และแท่งรวมที่ดู "ชัด" ก็มีจุดข้อมูลน้อยลงด้วย

2. เสียงรบกวนโตตาม √T แต่ drift โตตาม T แท่งยาวจึงเห็นทิศชัดกว่า ส่วนแท่งสั้นเกือบโยนเหรียญ และต้นทุนต่อรอบใหญ่กว่า σ หลายเท่า (1 นาที = 4.52 เท่าตามสมมติฐานวันนี้)

3. ใช้หลาย timeframe แบบมีหน้าที่ล่วงหน้า (ใหญ่ = ทิศ กลาง = เหตุผล เล็ก = จังหวะ) และวัดระยะ stop เป็นหลาย σ ของช่วงที่ถือ ไม่ใช่ % ที่รู้สึกสบายใจ
