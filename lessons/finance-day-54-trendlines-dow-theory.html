เส้นแนวโน้มและ Dow Theory

เส้นเฉียงที่ลากตามก้นและยอดบอกว่า "เทรนด์ยังอยู่" แต่เส้นที่ลากจากอดีตมีข้อมูลเกี่ยวกับอนาคตหรือไม่ วันนี้เริ่มจากทฤษฎีดั้งเดิมของ Dow แล้วทดสอบกับกราฟเหรียญอีกครั้ง โดยลากเส้นจากข้อมูลก่อนจุดตัดเท่านั้น ไม่โกงด้วยการมองอนาคต

Dow Theory: ต้นตอของการอ่านเทรนด์

Charles Dow (บรรณาธิการ Wall Street Journal เสียชีวิตปี 1902) เขียนบทความเรื่องพฤติกรรมของราคาเฉลี่ยตลาด ต่อมา William Hamilton และ Robert Rhea นำมารวบรวมเป็นที่เรียกกันว่า Dow Theory แก่นของทฤษฎีมีหกข้อ:

  1. ราคาสะท้อนข้อมูลทั้งหมดแล้ว (the averages discount everything) ข้อนี้ใกล้เคียงสมมติฐานตลาดมีประสิทธิภาพที่เห็นใน Day 33
  2. เทรนด์มีสามระดับ: ระดับหลัก (primary) ยาวหลายเดือนถึงหลายปี ระดับรอง (secondary) เป็นการย่อหรือเด้งสวนในระดับหลักนานหลายสัปดาห์ถึงหลายเดือน และระดับย่อย (minor) ผันผวนรายวันถึงรายสัปดาห์
  3. เทรนด์หลักมีสามช่วง: สะสม (accumulation) ตลาดร่วม (public participation) และเกินพอดี (excess)
  4. ดัชนีต้องยืนยันกัน (confirmation) ดั้งเดิมคือกลุ่มอุตสาหกรรมและกลุ่มขนส่งต้องทำจุดสูงใหม่ร่วมกัน
  5. ปริมาณซื้อขายต้องยืนยันเทรนด์ ขึ้นแรงเมื่อวอลุ่มหนา
  6. เทรนด์ยังอยู่จนกว่าจะมีสัญญาณกลับตัวชัดเจน

ทุกข้อเป็นข้อเสนอที่ฟังขึ้น แต่ "เทรนด์" ถูกนิยามกำกวม จึงทดสอบไม่ได้ วันนี้ใช้นิยามเชิงปฏิบัติการ: ขาขึ้น (uptrend) = จุดสูงสุดสูงขึ้นและจุดต่ำสุดสูงขึ้น (HH + HL) ขาลง = จุดสูงต่ำลงและจุดต่ำต่ำลง (LH + LL) นอกนั้นคือ "ไม่ชัด" โดยจุดสูง-ต่ำคือจุดกลับตัว (pivot) แบบ Day 53 คือแท่งที่สูงสุดหรือต่ำสุดเหนือเพื่อนบ้าน k แท่งสองข้าง (ใช้ k = 4) และเส้นแนวโน้ม (trendline) คือเส้นตรงผ่านจุดต่ำสองจุดล่าสุดที่ไล่ขึ้น (เส้นรับ) หรือจุดสูงสองจุดล่าสุดที่ไล่ลง (เส้นต้าน) ตำราบอกว่าถ้าราคาปิดทะลุเส้น แปลว่าเทรนด์อาจจบ

ตัวอย่าง: เส้นรับเป็นที่วาง stop

เต้นเห็นหุ้น ก. ทำจุดต่ำที่แท่ง 10 ราคา 46.00 และที่แท่ง 30 ราคา 50.00 เส้นรับจึงชัน (50.00 − 46.00) ÷ 20 = 0.20 บาทต่อแท่ง ค่าของเส้นที่แท่ง 40 = 52.00, แท่ง 45 = 53.00, แท่ง 50 = 54.00 สมมติราคาอยู่ที่ 53.40 และเต้นวาง stop ใต้เส้นที่ 53.00 ระยะห่าง 0.40 บาท = 0.40 ÷ 0.60 = 0.67σ (σ รายแท่ง 0.60 บาท) โอกาสที่เสียงรบกวนล้วนๆ พาราคาแตะระดับที่ห่างลงไป d ภายใน T แท่ง (หลักการสะท้อน, reflection principle) คือ P = 2Φ(−d ÷ (σ√T)) ได้ 1 แท่ง 50.5%, 4 แท่ง 73.9%, 9 แท่ง 82.4% เส้นที่ "ดูใกล้" ถูกแตะง่ายกว่าที่ตาเห็น ลองปรับเอง:

หมายเหตุเรื่องการลากเส้น: เส้นตรงบนแกนราคาปกติ (arithmetic) ต่างจากบนแกน log เมื่อราคาโตเป็นสัดส่วน เช่น 40 → 48 ใน 20 แท่ง (+20%) ที่แท่ง 40 เส้นตรงให้ 56.00 แต่เส้น log (โตเท่ากันเป็น %) ให้ 40 × 1.2² = 57.60 ต่างกัน 1.60 บาท (2.9%) เส้นแนวโน้มยาวๆ จึงมีตัวเลือกให้เลือกอีกปุ่มหนึ่ง ซึ่งก็คือปุ่มที่ปรับจนเข้าตาได้

กฎใช้เส้นแนวโน้มให้ไม่หลอกตัวเอง

เขียนนิยามก่อนดูกราฟ: ค่า k, จุดไหนนับ, ราคาปิดทะลุกี่ σ จึงนับว่าหลุด และใช้แกนปกติหรือ log

ทดสอบแบบ walk-forward: ลากเส้นด้วยข้อมูลก่อนวันตัด แล้วดูอนาคตเท่านั้น เส้นที่ลากหลังรู้ผลแล้วสวยเสมอ

วัด stop เป็นหลาย σ ของช่วงที่ถือ: เส้นที่ห่าง 0.67σ ถูกแตะง่ายด้วยสัญญาณรบกวนล้วนๆ และราคา gap ข้ามเส้นได้ ขาดทุนจริงจึงอาจมากกว่าที่วางแผน

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
import math
import numpy as np
from numpy.lib.stride_tricks import sliding_window_view

Phi = lambda z: 0.5 * (1 + math.erf(z / math.sqrt(2)))

# 1) เส้นรับผ่าน (10, 46.00) และ (30, 50.00)
slope = (50 - 46) / (30 - 10)               # 0.20 บาท/แท่ง
print(slope, 46 + slope * (45 - 10))        # 0.2, 53.0

# 2) โอกาสแตะเส้น/stop ห่าง d ภายใน T แท่ง (เดินสุ่มไม่มี drift)
def touch(d, sigma, T): return 2 * Phi(-d / (sigma * math.sqrt(T)))
print([round(touch(0.40, 0.60, T), 4) for T in (1, 4, 9)])  # 0.505, 0.7389, 0.8241

# 3) จำลอง: ทะลุเส้นรับแล้วอีก 10 แท่งเป็นอย่างไร
rng = np.random.default_rng(54)
N, k = 400_000, 5
x = np.cumsum(rng.normal(0, 1, N))
w = sliding_window_view(x, 2 * k + 1)
lows = np.where(w[:, k] == w.min(axis=1))[0] + k
res = []
for a, b in zip(lows[:-1], lows[1:]):
    if x[b] <= x[a]: continue                # ต้องเป็นก้นที่ไล่ขึ้น
    s = (x[b] - x[a]) / (b - a); t0 = b + k  # ยืนยันที่ b+k
    if t0 + 60 >= N: break
    if x[t0] <= x[b] + s * (t0 - b): continue
    seg = np.arange(t0, min(t0 + 3000, N - 20))
    br = np.where(x[seg] < x[b] + s * (seg - b))[0]
    if len(br) == 0: continue
    tb = seg[br[0]]
    res.append(x[tb + 10] - x[tb])
res = np.array(res)
print(len(res), (res < 0).mean(), res.mean())   # ~9985, ~0.494, ~+0.07

ทดสอบความเข้าใจ

1. เส้นรับผ่านจุดต่ำ (แท่ง 10, 46.00) และ (แท่ง 30, 50.00) ค่าของเส้นที่แท่ง 45 เท่าไร และถ้าราคาปิดแท่งนั้นที่ 52.80 (σ รายแท่ง 0.60 บาท) หลุดเส้นไปกี่ σ

ดูเฉลย
ความชัน = 4.00 ÷ 20 = 0.20 บาทต่อแท่ง · ที่แท่ง 45 = 46.00 + 0.20 × 35 = 53.00 · ปิด 52.80 หลุดไป 0.20 บาท = 0.20 ÷ 0.60 = 0.33σ ซึ่งอยู่ในช่วงสัญญาณรบกวนปกติของแท่งเดียว การนับว่า "เทรนด์จบ" จากการหลุดเท่านี้จึงให้สัญญาณหลอกง่าย ควรกำหนดล่วงหน้าว่าต้องหลุดกี่ σ หรือกี่แท่ง

2. ราคาอยู่เหนือเส้นรับ 0.40 บาท σ รายแท่ง 0.60 บาท โอกาสที่เสียงรบกวนล้วนๆ พาราคาแตะเส้นภายใน 1 แท่ง และภายใน 4 แท่งคือเท่าไร (ใช้ 2Φ(−d ÷ (σ√T)))

ดูเฉลย
T = 1: d ÷ σ = 0.667 ⇒ 2Φ(−0.667) = 2 × 0.2525 = 50.5% · T = 4: d ÷ (σ√T) = 0.40 ÷ 1.20 = 0.333 ⇒ 2Φ(−0.333) = 2 × 0.3694 = 73.9% ยิ่งถือนาน ยิ่งมีโอกาสโดน stop ที่วางใกล้เส้น

3. ราคาโตจาก 40 เป็น 48 (+20%) ใน 20 แท่ง ถ้าโตเป็นสัดส่วนเท่าเดิมต่อไปอีก 20 แท่ง ที่แท่ง 40 เส้นตรงบนแกนปกติให้ค่าเท่าไร เส้นบนแกน log ให้เท่าไร ต่างกันกี่ %

ดูเฉลย
เส้นตรง: 40 + 0.40 × 40 = 56.00 · เส้น log: 40 × 1.202 = 57.60 · ต่าง 1.60 บาท = 1.60 ÷ 56.00 = 2.86% การเลือกแกนทำให้เส้นเดียวกันชี้ไปคนละที่ เป็นอีกหนึ่ง "ปุ่ม" ที่ต้องกำหนดก่อนดูกราฟ

ทวน: Day 50 · เต้นซื้อ 1,000 หุ้นที่ 50.00 ตั้ง stop-loss แบบขายตามราคาตลาดเมื่อราคาแตะ 48.00 ถ้าวันถัดมาราคาเปิด gap ลงที่ 45.00 และขายได้ที่ 45.00 ขาดทุนเท่าไร เทียบกับที่วางแผนไว้

ดูเฉลย
ที่วางแผน = (48.00 − 50.00) × 1,000 = −2,000 บาท · ที่เกิดจริง = (45.00 − 50.00) × 1,000 = −5,000 บาท (มากกว่าแผน 2.5 เท่า) stop ไม่รับประกันราคา เส้นแนวโน้มก็ไม่ได้ป้องกัน gap

ทวน: Day 51 · ราคาแรก 50.00 สูงสุด 52.00 ต่ำสุด 49.00 ราคาสุดท้าย 51.50 ของแท่งเทียน ขนาดตัวเทียน (body) เงาบน เงาล่าง และ body ÷ range เป็นเท่าไร

สรุป 3 บรรทัด

1. Dow Theory แบ่งเทรนด์เป็นหลัก รอง ย่อย และถือว่าเทรนด์ยังอยู่จนกว่าจะมีสัญญาณกลับตัว นิยามที่ทดสอบได้คือขาขึ้น = HH+HL แต่กราฟเหรียญก็มีสถานะขาขึ้นหรือขาลงชัดเจน 63.9% และเส้นที่ใช้ได้ถูกทะลุภายใน 40 แท่ง ราว 76%
