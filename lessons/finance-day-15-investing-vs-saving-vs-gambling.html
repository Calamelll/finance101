Day 15 / 90 Phase 2 · การลงทุนระยะยาว (บทเปิด) · อ่าน 8 นาที

การลงทุนคืออะไร ต่างจากการออมและการพนัน

Phase 1 วางเครื่องมือพื้นฐานครบแล้ว ตั้งแต่วันนี้เข้าสู่ Phase 2 (Day 15-47) ว่าด้วยการลงทุนระยะยาว ก่อนพูดถึงหุ้น กองทุน หรือพันธบัตร ต้องตอบคำถามพื้นฐานที่สุดก่อน: "ลงทุน" ต่างจาก "ออมเงิน" และ "เล่นพนัน" ตรงไหน เพราะคนจำนวนมากสับสนสามอย่างนี้ และบางคนก็เอาเงินไปเสี่ยงแบบพนันโดยคิดว่ากำลัง "ลงทุน"

สามอย่างที่คนมักปนกัน

ทั้งสามกิจกรรมมีจุดร่วมเดียวกันคือ "เอาเงินวันนี้ไปแลกกับเงินในอนาคตที่ไม่แน่นอน" แต่ต่างกันตรง ที่มาของผลตอบแทน และ ค่าคาดหวังทางคณิตศาสตร์ (expected value) ของกิจกรรมนั้น

มิติออม (saving)ลงทุน (investing)พนัน (gambling)
เป้าหมายรักษาเงินต้น + สภาพคล่องเพิ่มมูลค่าเงินระยะยาวความบันเทิง/ลุ้นโชค
ที่มาผลตอบแทนดอกเบี้ยจากธนาคารกำไร/ปันผลจากธุรกิจจริง หรือดอกเบี้ยจากการให้กู้ยืมเงินจากผู้เล่นคนอื่นที่แพ้
Expected valueเป็นบวกเล็กน้อย เกือบไม่มีความเสี่ยงเป็นบวกในระยะยาว แต่ผันผวนระยะสั้นเป็นลบเสมอ (มีเจ้ามือ/รัฐหักส่วนแบ่งก่อน)
กรอบเวลาสั้น-กลางยาว (ปี-สิบปี)สั้นมาก (นาที-วัน)
ความเสี่ยงเงินต้นแทบไม่มี (ในบัญชีที่คุ้มครองแล้ว)มี ผันผวนขึ้นลงได้จริงสูญเงินทั้งหมดได้ในครั้งเดียว

ตัวที่แยก "ลงทุน" ออกจาก "พนัน" ได้ชัดที่สุดไม่ใช่ความเสี่ยง (ทั้งคู่มีความเสี่ยงสูญเงินได้) แต่คือ expected value เป็นบวกหรือลบ และคำถามต่อไปคือทำไม expected value ของการลงทุนถึงเป็นบวกได้ในขณะที่การพนันเป็นลบเสมอ

ทำไม expected value ของการลงทุนถึงเป็นบวกได้

เวลาซื้อหุ้นบริษัทหนึ่ง เท่ากับเป็นเจ้าของส่วนหนึ่งของธุรกิจที่ผลิตสินค้า ขายบริการ และทำกำไรจริง กำไรนั้นตกเป็นของผู้ถือหุ้นในรูปเงินปันผลหรือมูลค่ากิจการที่โตขึ้น เวลาซื้อพันธบัตรหรือหุ้นกู้ เท่ากับให้บริษัทหรือรัฐบาลกู้เงินไปใช้ แล้วได้ดอกเบี้ยเป็นค่าตอบแทนที่ยอมให้ "ใช้เงินของเรา" การลงทุนจึงผูกอยู่กับ กิจกรรมทางเศรษฐกิจที่สร้างมูลค่าจริง — เศรษฐกิจโดยรวมเติบโต บริษัทผลิตของได้มากขึ้น มีประชากรและเทคโนโลยีเพิ่มผลิตภาพ กำไรรวมของระบบจึงมีแนวโน้มเป็นบวกในระยะยาว แม้แต่ละปีจะขึ้นลงไม่แน่นอน

การพนันไม่มีกิจกรรมสร้างมูลค่าใดๆ อยู่เบื้องหลัง เงินที่ผู้เล่นวางเดิมพันรวมกันทั้งหมด ถูกหักส่วนหนึ่งออกไปเป็นกำไรของเจ้ามือหรือค่าดำเนินการ/ภาษี ก่อน ที่จะเหลือแบ่งคืนเป็นเงินรางวัล ทำให้ผลรวมของทุกคนที่เล่นเป็นลบเสมอ (negative-sum game) ไม่ว่าใครจะเก่งหรือโชคดีแค่ไหน เงินก้อนที่หายไปนั้นไม่ได้ไปสร้างโรงงาน จ้างงาน หรือเพิ่มผลผลิตใดๆ ให้เศรษฐกิจ สลากกินแบ่งรัฐบาลเป็นตัวอย่างที่ชัด: กฎหมายกำหนดสัดส่วนเงินรางวัลไว้ล่วงหน้าต่ำกว่ามูลค่าสลากที่ขายทั้งหมด ส่วนต่างจึงเป็นต้นทุนแฝงที่ผู้ซื้อทุกคนแบกรับรวมกัน ทำให้ expected value ติดลบโดยโครงสร้าง ไม่ใช่เพราะดวงไม่ดี

ข้อควรระวัง: "ลงทุน" ที่จริงคือพนันแฝง

การซื้อหุ้นถือเป็นวันแล้วขายทำกำไรสั้นๆ โดยไม่สนใจว่าธุรกิจดีหรือไม่ ก็ยังเรียกว่าการลงทุนได้ในทางเทคนิค แต่ถ้าไม่มีเหตุผลเชิงมูลค่าธุรกิจรองรับเลย และหวังแค่ "ราคาขึ้นเพราะคนอื่นก็ซื้อ" กลไกที่ขับเคลื่อนผลตอบแทนตอนนั้นใกล้เคียงการพนันมากกว่าการลงทุน เพราะไม่ได้อิงกับกำไรหรือมูลค่าที่ธุรกิจสร้างจริง

ตัวอย่างตัวเลขจริง: เงิน 10,000 บาทไปทางไหนบ้าง

สมมตินักศึกษาคนหนึ่งมีเงินเก็บ 10,000 บาท และเลือกทำอย่างใดอย่างหนึ่งใน 3 ทางเป็นเวลา 10 ปี: เก็บเป็นเงินสด (0% ต่อปี) ฝากออมทรัพย์ดิจิทัล (สมมติ 1% ต่อปี ซึ่งอยู่ในช่วงที่เคยดูใน Day 9) หรือลงทุนระยะยาวในสินทรัพย์ที่ให้ผลตอบแทนเฉลี่ยสมมติ 8% ต่อปี (ตัวเลขสมมติกลมๆ เพื่อการอธิบาย ไม่ใช่การพยากรณ์ผลตอบแทนจริงของตลาดใดตลาดหนึ่ง)

เห็นได้ชัดว่าเงินสดไม่โตเลยเพราะไม่มีผลตอบแทนใดๆ และยังถูกเงินเฟ้อกัดกินมูลค่าจริงอยู่ตลอด (Day 4) ออมทรัพย์โตช้าแต่มั่นคง ส่วนการลงทุนให้ผลตอบแทนสูงกว่ามากในระยะยาวแลกกับความเสี่ยงที่ต้องยอมรับว่าบางปีอาจติดลบ นี่คือเหตุผลที่เงินสำรองฉุกเฉิน (Day 7) ควรอยู่ในบัญชีสภาพคล่องสูงอย่างออมทรัพย์ ไม่ใช่เอาไปลงทุนเสี่ยง เพราะจุดประสงค์ของเงินก้อนนั้นคือ "พร้อมใช้ทันที" ไม่ใช่ "โตสูงสุด"

ลองเปรียบเทียบด้วยตัวเอง

ปรับจำนวนปีและอัตราผลตอบแทนสมมติของ "ทางเลือกลงทุน" เพื่อดูว่าเงิน 10,000 บาทตั้งต้นจะต่างกันแค่ไหนเมื่อเทียบกับเก็บเป็นเงินสดเฉยๆ

เงินสด (0%)
ออมทรัพย์ (1%)
ลงทุน
กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน)

สูตร future value แบบดอกเบี้ยทบต้นรายปี ตรวจสอบด้วย Python ก่อนใส่ตัวเลขในบทเรียนแล้ว:

def fv(principal, rate, years):
    return principal * (1 + rate) ** years

p = 10000
for years in (1, 3, 5, 10):
    cash = fv(p, 0.00, years)
    save = fv(p, 0.01, years)
    invest = fv(p, 0.08, years)
    print(years, round(cash), round(save), round(invest))
# 1  10000 10100 10800
# 3  10000 10303 12597
# 5  10000 10510 14693
# 10 10000 11046 21589

ทดสอบความเข้าใจ

1. อะไรคือตัวแยก "การลงทุน" กับ "การพนัน" ที่ชัดเจนที่สุด ทั้งที่ทั้งคู่มีความเสี่ยงสูญเงินได้เหมือนกัน?

ดูเฉลย
Expected value (ค่าคาดหวังทางคณิตศาสตร์) ของผลตอบแทน การลงทุนมี expected value เป็นบวกในระยะยาวเพราะผูกกับกิจกรรมทางเศรษฐกิจที่สร้างมูลค่าจริง (กำไรธุรกิจ ดอกเบี้ยจากการให้กู้ยืม) ส่วนการพนันมี expected value เป็นลบเสมอ เพราะเจ้ามือ/รัฐหักส่วนแบ่งออกจากเงินเดิมพันรวมก่อนแบ่งคืนเป็นรางวัลเสมอ ความเสี่ยงเพียงอย่างเดียวไม่ใช่ตัวแยก เพราะทั้งสองอย่างมีความผันผวนได้

2. ทำไมเงินสำรองฉุกเฉินถึงควรอยู่ในบัญชีออมทรัพย์ ไม่ใช่เอาไปลงทุนในสินทรัพย์เสี่ยงที่ให้ผลตอบแทนสูงกว่า?

ดูเฉลย
เพราะจุดประสงค์ของเงินสำรองฉุกเฉินคือความพร้อมใช้ทันทีเมื่อเกิดเหตุไม่คาดฝัน ไม่ใช่การเติบโตสูงสุด สินทรัพย์เสี่ยงอาจติดลบในช่วงเวลาที่บังเอิญต้องใช้เงินพอดี ทำให้ต้องขายขาดทุนหรือสภาพคล่องไม่พอ ส่วนบัญชีออมทรัพย์แม้ผลตอบแทนต่ำแต่ถอนได้ทันทีและมูลค่าไม่ผันผวน ตรงกับหน้าที่ของเงินก้อนนี้มากกว่า

3. ทำไมการซื้อหุ้นถือสั้นๆ โดยไม่สนใจพื้นฐานธุรกิจ ถึงถูกมองว่าใกล้เคียงการพนันมากกว่าการลงทุน แม้จะเรียกว่า "ซื้อหุ้น" เหมือนกัน?

ดูเฉลย
เพราะกลไกที่ขับเคลื่อนผลตอบแทนไม่ได้อิงกับกำไรหรือมูลค่าที่ธุรกิจสร้างจริง แต่หวังพึ่งการที่ราคาขึ้นเพราะมีคนอื่นซื้อต่อ (ใกล้เคียง zero-sum ระหว่างผู้ซื้อขายกันเอง) ต่างจากการลงทุนที่ผลตอบแทนผูกกับกิจกรรมทางเศรษฐกิจที่สร้างมูลค่าเพิ่มจริงในระยะยาว

ทวน: ดอกเบี้ยทบต้น (compound interest) ต่างจากดอกเบี้ยแบบธรรมดา (simple interest) อย่างไร และทำไมยิ่งเวลานานผลต่างยิ่งมาก?

ดูเฉลย
ดอกเบี้ยทบต้นคำนวณจากเงินต้นบวกดอกเบี้ยที่สะสมไว้แล้วในแต่ละงวด ทำให้ดอกเบี้ยงวดถัดไปคำนวณจากฐานที่ใหญ่ขึ้นเรื่อยๆ ต่างจากดอกเบี้ยแบบธรรมดาที่คำนวณจากเงินต้นเดิมทุกงวด ยิ่งเวลานาน ฐานที่ใช้คำนวณดอกเบี้ยทบต้นยิ่งห่างจากเงินต้นเดิมมากขึ้นแบบทวีคูณ ผลต่างจึงเห็นชัดในระยะยาวมากกว่าระยะสั้น

ทวน: บัญชีออมทรัพย์ดิจิทัล (e-Savings) มักให้ดอกเบี้ยสูงกว่าบัญชีออมทรัพย์ปกติเพราะอะไร?

ดูเฉลย
เพราะเปิดผ่านแอปมือถือเท่านั้น ธนาคารประหยัดต้นทุนสาขาและพนักงานหน้าเคาน์เตอร์ จึงนำส่วนที่ประหยัดได้มาจ่ายดอกเบี้ยคืนลูกค้าในอัตราที่สูงกว่า เป็นตัวอย่างของหลักการ trade-off ระหว่างสภาพคล่อง ต้นทุนธนาคาร และผลตอบแทนที่ลูกค้าได้รับ

สรุป 3 บรรทัด

1. ออม ลงทุน และพนัน ต่างกันที่ที่มาของผลตอบแทนและ expected value ไม่ใช่แค่ระดับความเสี่ยง

2. การลงทุนมี expected value เป็นบวกในระยะยาวเพราะผูกกับกิจกรรมทางเศรษฐกิจที่สร้างมูลค่าจริง ขณะที่การพนันมี expected value เป็นลบเสมอเพราะเจ้ามือหักส่วนแบ่งก่อนแบ่งคืนรางวัล

3. เงินแต่ละก้อนมีหน้าที่ต่างกัน — เงินสำรองฉุกเฉินต้องการสภาพคล่อง ไม่ใช่ผลตอบแทนสูงสุด ส่วนเงินเป้าหมายระยะยาวถึงจะเหมาะกับการลงทุน

พรุ่งนี้ Day 16 — ความเสี่ยงกับผลตอบแทน (risk-return tradeoff) เจาะลึกว่าทำไมผลตอบแทนที่สูงกว่าต้องแลกกับความเสี่ยงที่มากกว่าเสมอ และวัดความเสี่ยงเชิงตัวเลขได้อย่างไร

บทเรียนนี้เป็นความรู้เชิงการศึกษา ไม่ใช่คำแนะนำทางการเงินเฉพาะบุคคล ตัวอย่างตัวเลขในบทเรียนสมมติขึ้นเพื่อการอธิบาย ผลตอบแทนการลงทุนจริงไม่แน่นอนและอาจขาดทุนได้ ควรปรึกษาผู้เชี่ยวชาญด้านการเงินก่อนตัดสินใจวางแผนจริง
