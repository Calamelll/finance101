Growth vs Value investing

เมื่อวานเราเห็นว่า g อยู่ในตัวหารและเปลี่ยนคำตอบได้เท่าตัว วันนี้จะพิสูจน์ด้วยสมการบรรทัดเดียวว่า "การเติบโต" ไม่ได้เพิ่มมูลค่าเสมอไป — มีเงื่อนไขอยู่ข้อเดียวที่ตัดสินว่าโตแล้วผู้ถือหุ้นรวยขึ้นหรือจนลง

สองสำนักที่ไม่ได้เป็นศัตรูกันอย่างที่เล่าขาน

ฝั่ง value investing เริ่มจาก Benjamin Graham ในทศวรรษ 1930: ซื้อของที่ราคาต่ำกว่ามูลค่าอย่างชัดเจน เผื่อส่วนต่างความปลอดภัย (margin of safety) ไว้เยอะๆ เพราะเราคาดการณ์อนาคตไม่เก่ง ฝั่ง growth investing เริ่มจาก Philip Fisher: ถ้าเจอธุรกิจที่โตได้จริงยาวนาน จ่ายแพงกว่าตลาดวันนี้ก็ยังคุ้ม เพราะเวลาอยู่ข้างเรา

แต่ Warren Buffett พูดประโยคที่ปิดการถกเถียงนี้ไปแล้วว่าทั้งสองคำ "ติดกันอยู่ที่สะโพก" — การเติบโตเป็นตัวแปรตัวหนึ่งในสมการมูลค่าเสมอ ไม่ใช่สมการคนละตัว สิ่งที่สองสำนักเถียงกันจริงๆ ไม่ใช่ "ถูก vs แพง" แต่คือ เราเชื่อตัวเลขชุดไหนมากกว่ากัน: งบการเงินที่เกิดขึ้นแล้ววันนี้ หรือประมาณการอีกสิบปีข้างหน้า

นิยามในอุตสาหกรรมจริงคือสูตร ไม่ใช่ความเห็น

MSCI ซึ่งเป็นผู้ทำดัชนีที่กองทุนทั่วโลกใช้อ้างอิง นิยามสองคำนี้แบบเครื่องจักร: value คัดจาก 3 ตัวแปร (มูลค่าทางบัญชีต่อราคา, กำไรล่วงหน้า 12 เดือนต่อราคา, อัตราปันผล) ส่วน growth คัดจาก 5 ตัวแปรที่เกี่ยวกับอัตราโตของกำไรและยอดขาย ทั้งย้อนหลังและคาดการณ์

ผลที่ตามมาทำให้คนส่วนใหญ่ตกใจ: ณ 31 ส.ค. 2569 หุ้นน้ำหนักอันดับ 1 ของ MSCI World Value Index คือ Microsoft (7.72%) ตามด้วย Meta (2.71%) และ Micron (2.33%) — กลุ่ม Information Technology คิดเป็น 17.2% ของดัชนี "คุณค่า" เพราะสูตรดูแค่ตัวเลข ไม่ได้ดูว่าบริษัททำอะไรหรือเล่าเรื่องอย่างไร บทเรียนใช้ได้ทันที: เวลาจะซื้อกองทุนที่มีคำว่า value หรือ growth ในชื่อ ต้องเปิดดูว่าสูตรคัดอะไรมาให้จริงๆ

สมการบรรทัดเดียวที่ตัดสินว่าโตแล้วดีหรือไม่ดี

Day 28 จบที่ P/E ที่สมเหตุสมผล = payout ÷ (r − g) วันนี้เติมอีกสองบรรทัดที่เชื่อมกลับไปหา ROE ของ Day 27 ถ้าบริษัทเก็บกำไรไว้ลงทุนต่อในสัดส่วน b (reinvestment rate) และเงินที่เก็บไว้ได้ผลตอบแทนเท่ากับ ROE เดิม กำไรจะโตในอัตรา g = b × ROE ส่วนที่เหลือจ่ายออกมาเป็นปันผล payout = 1 − b แทนกลับเข้าไป:

P/E = (1 − b) ÷ (r − b·ROE)
ถ้า ROE = r พอดี ⇒ P/E = (1−b) ÷ (r(1−b)) = 1/r — ตัด (1−b) ทิ้งได้ทั้งบน
แปลว่า P/E ไม่ขึ้นกับการเติบโตเลย ไม่ว่าบริษัทจะเก็บกำไรไว้ 0% หรือ 90%

ทฤษฎีบทเล็กๆ นี้เปลี่ยนวิธีมองหุ้นทั้งหมด การเติบโตเพิ่มมูลค่าเมื่อ ROE > r, ไม่ทำอะไรเลยเมื่อ ROE = r, และ ทำลายมูลค่าเมื่อ ROE < r ลองที่ r = 9% และเก็บกำไรไว้ 30% เท่ากันทั้งสามบริษัท:

กับดักคนละแบบของสองฝั่ง

Value trap: หุ้น P/E 5 เท่าที่กำไรหดปีละ 10% ตลอดไป ถ้า r = 12% และจ่ายปันผลหมด P/E ที่สมควรคือ 1 ÷ (0.12 + 0.10) = 4.55 เท่า แปลว่า P/E 5 นั้นแพงกว่ามูลค่า 10% ไม่ใช่ถูก สูตรคัดหุ้นเห็นแค่เลข 5 แต่ไม่รู้ว่าตัวหารกำลังละลาย

Growth trap: จ่าย P/E สูงให้บริษัทที่ ROE ต่ำกว่า r แล้วเก็บกำไรไว้ขยายตัว — ตามตารางข้างบน ยิ่งขยายยิ่งควรถูกตีราคาต่ำ นักลงทุนจ่ายแพงเพื่อซื้อการเผาเงินที่ดูเหมือนการเติบโต

บริบทไทย: อ่านเป้าดัชนีให้เป็นสมมติฐานสองตัว

บล. ดีบีเอส วิคเคอร์ส (ประเทศไทย) แถลงเมื่อ 27 ส.ค. 2569 ปรับเป้า SET Index สิ้นปี 2569 ขึ้นเป็น 1,720 จุด จากเดิม 1,650 จุด โดยอิง forward P/E 16.7 เท่า และคาดกำไรบริษัทจดทะเบียนโต 9% ในปี 2569 และ 4% ในปี 2570

แกะกลับด้วยสิ่งที่เรียนมา: 1,720 ÷ 16.7 = EPS ของดัชนี 102.99 จุด เทียบกับ SET ที่ปิด 1,583.34 จุด (18 ก.ย. 2569) บน EPS 100.50 = P/E 15.75 เท่า ⇒ upside 8.63% ทั้งหมดของ "เป้า 1,720" จึงมีแค่สองสมมติฐาน: กำไรจะโตเท่าไร กับ ตลาดจะยอมจ่ายกี่เท่า — ไม่มีอะไรมากกว่านั้นเลย และตัวเลข 4% ของปี 2570 บอกชัดว่าโมเดลนี้ไม่ได้มองตลาดไทยเป็นตลาดเติบโต พอรู้แบบนี้แล้วเวลาเจอบทวิเคราะห์ เราจะเถียงกับสมมติฐานได้ แทนที่จะเชื่อตัวเลขสุดท้ายตามไป

ที่มา: กรุงเทพธุรกิจ 27 ส.ค. 2569 (บล. ดีบีเอส วิคเคอร์ส) · ระดับดัชนีและ EPS จาก set.or.th ณ 17–18 ก.ย. 2569 · ตัวเลขเหล่านี้เป็นความเห็นของสำนักวิจัย ไม่ใช่ข้อเท็จจริง และเปลี่ยนได้ทุกวัน

เงินฝึกงานเดือนแรก 10,000 บาท ทิ้งไว้ 40 ปีจนถึงวัยเกษียณ ที่ 11.68% ต่อปีจะกลายเป็น 829,882 บาท ที่ 10.75% จะได้ 593,949 บาท · ส่วนต่าง 235,933 บาทมาจากความต่างปีละไม่ถึง 1 จุด · แต่ประเด็นไม่ใช่ให้ไปเลือกฝั่ง — ประเด็นคือจำนวนปีในเลขชี้กำลังมีค่ามากกว่าการเลือกสำนัก และตอนนี้เต้นมีตัวแปรนั้นมากกว่าคนเกือบทั้งตลาด

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
def justified_pe(roe, b, r):
    """P/E ที่สมควร เมื่อ g = b*ROE และ payout = 1-b"""
    g = b * roe
    return float('inf') if g >= r else (1 - b) / (r - g)

r = 0.12
for roe in (0.20, 0.12, 0.08):
    row = [justified_pe(roe, b, r) for b in (0.0, 0.2, 0.4)]
    print(f"ROE {roe:5.0%} | " + "  ".join(f"{x:6.2f}" for x in row))

# ROE   20% |   8.33   10.00   15.00   <- โตแล้วแพงขึ้น  (ROE > r)
# ROE   12% |   8.33    8.33    8.33   <- โตแล้วเท่าเดิม (ROE = r)
# ROE    8% |   8.33    7.69    6.82   <- โตแล้วถูกลง    (ROE < r)

แถวกลางคือทฤษฎีบททั้งหมดในสามตัวเลข: เมื่อ ROE = r การเติบโตหายไปจากสมการสนิท

2. จากการ์ดดัชนี MSCI ณ 31 ส.ค. 2569 จงใช้เอกลักษณ์ของ Day 27 หา ROE และ payout ที่แฝงอยู่ในดัชนี growth แล้วหา g ยั่งยืน · ตัวเลขนั้นเป็นไปได้ตลอดกาลไหม และมันบอกอะไรเกี่ยวกับ P/E 30.10 เท่า

payout = อัตราปันผล × P/E = 0.70% × 30.10 = 21.07% ⇒ b = 78.93%

เป็นไปไม่ได้ตลอดกาล — Day 28 บอกว่า g ต้องน้อยกว่า r ไม่งั้นสมการระเบิด และเศรษฐกิจโลกโตราว 2–4% บริษัทที่โต 21% ตลอดกาลจะกลืนทั้งโลกในไม่กี่ทศวรรษ · แต่สิ่งที่ตัวเลขนี้บอกจริงๆ คือ P/E 30.10 ไม่ได้แปลว่าตลาดเชื่อ 21% ตลอดไป แต่เชื่อว่าช่วงโตแรงจะยาวพอจะคุ้มราคา · สังเกตว่า ROE 26.78% สูงกว่า r ที่ไหนๆ ก็เรียกกัน แปลว่าธุรกิจกลุ่มนี้ดีจริงและการโตของมันเพิ่มมูลค่าจริงตามทฤษฎีบทวันนี้ · ความเสี่ยงอยู่ที่ราคาที่จ่าย ไม่ใช่คุณภาพธุรกิจ ซึ่งเป็นความเสี่ยงคนละชนิดกับ growth trap

สรุป 3 บรรทัด

1. growth ไม่ใช่ฝั่งตรงข้ามของ value แต่เป็นตัวแปรในสมการเดียวกัน: P/E = (1 − b) ÷ (r − b·ROE) · การโตเพิ่มมูลค่าเมื่อ ROE > r, เป็นกลางสนิทเมื่อ ROE = r (P/E = 1/r เสมอ ไม่ว่าจะโตแค่ไหน) และทำลายมูลค่าเมื่อ ROE < r

2. 51 ปี 8 เดือน ฝั่ง value ชนะ 11.68% ต่อ 10.75% ต่อปี (301 เท่า ต่อ 195 เท่า) แต่ 10 ปีล่าสุด growth ชนะกลับ 15.53% ต่อ 11.14% · และทั้งคู่เคยขาดทุนเกิน 57% มาแล้ว แค่คนละรอบ — ช่วงเวลาที่เลือกวัด เปลี่ยนข้อสรุปได้ทั้งหมด

3. ที่ P/E 30 หุ้นเติบโตต้องโต EPS 11.60% ต่อปีสิบปีติด เพียงเพื่อเสมอกับหุ้น P/E 12 ที่โตแค่ 3% · ราคาที่เราจ่ายไม่ใช่ป้ายราคา แต่เป็นสมมติฐานที่เราต้องรับผิดชอบแทนบริษัท

พรุ่งนี้ Day 30 — วัฏจักรธุรกิจและกลุ่มอุตสาหกรรม (sector) สังเกตไหมว่าดัชนี growth มี IT 42.7% ส่วนดัชนี value มีกลุ่มการเงิน 26.1% — มันไม่ใช่เรื่องบังเอิญ พรุ่งนี้จะดูว่าทำไมบางกลุ่มอุตสาหกรรมถึงได้ P/E สูงกว่าอีกกลุ่มอย่างถาวร กลุ่มไหนขึ้นลงตามเศรษฐกิจ (cyclical) กลุ่มไหนไม่สน (defensive) และทำไมหุ้นวัฏจักรถึงดูถูกที่สุดตอนที่มันแพงที่สุดจริงๆ

บทเรียนนี้เป็นความรู้เชิงการศึกษา ไม่ใช่คำแนะนำทางการเงินเฉพาะบุคคล และไม่ใช่การชี้ชวนให้ซื้อหรือขายหลักทรัพย์ กองทุน หรือดัชนีใด · ชื่อบริษัทและหุ้นที่ปรากฏถูกอ้างถึงเพื่ออธิบายวิธีการคัดหุ้นของดัชนีเท่านั้น ไม่ใช่การแนะนำ · บริษัทสมมติ ก. ข. ค. ฎ. และ ฏ. รวมถึงสมมติฐาน r 9% และ 12% ถูกสร้างขึ้นให้คำนวณตามง่าย ไม่ใช่ข้อมูลจริงของบริษัทใด · ข้อมูลดัชนี MSCI เป็น gross return สกุลดอลลาร์สหรัฐ ณ 31 ส.ค. 2569 ซึ่งไม่หักภาษีหัก ณ ที่จ่าย ค่าธรรมเนียม หรือผลของอัตราแลกเปลี่ยน และข้อมูลก่อนวันเปิดตัวดัชนี (8 ธ.ค. 2540) เป็นการคำนวณย้อนหลัง (back-tested) ซึ่งมักต่างจากผลจริง · ผลตอบแทนในอดีตไม่ได้บ่งชี้ผลตอบแทนในอนาคต · เป้าดัชนีและประมาณการกำไรเป็นความเห็นของสำนักวิจัยที่อ้างถึง ณ วันที่ระบุ ไม่ใช่ข้อเท็จจริงและเปลี่ยนแปลงได้ตลอดเวลา
