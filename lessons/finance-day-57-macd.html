MACD และการอ่านสัญญาณ

MACD (moving average convergence divergence) คือผลต่างของ EMA สองเส้นจาก Day 55 บวกเส้นสัญญาณและฮิสโทแกรม วันนี้พิสูจน์ว่าสามส่วนนี้คืออะไรในเชิงคณิตศาสตร์ มันเป็นตัวประมาณ "ความชัน" ของราคา และสัญญาณที่เห็นเกิดถี่แค่ไหนในโลกสุ่ม

สามส่วนของ MACD

Gerald Appel เสนอ MACD ในปลายทศวรรษ 1970 ค่ามาตรฐานคือ (12, 26, 9) ใช้ EMA ที่ α = 2 ÷ (N+1) ตามที่เรียนใน Day 55 สามส่วนคือ:

MACD = EMA12 − EMA26  ·  Signal = EMA9(MACD)  ·  Hist = MACD − Signal
ใช้ราคาปิด · MACD มีหน่วยเป็น "บาท" (หน่วยเดียวกับราคา) · Signal คือ EMA ของ MACD อีกชั้น · ฮิสโทแกรม (histogram) เป็นบวกเมื่อ MACD อยู่เหนือ Signal

สังเกตว่าทั้งสามส่วนสร้างจาก EMA ล้วนๆ จึงไม่มีข้อมูลใหม่นอกจากราคาปิดที่ผ่านมา ผลสำคัญสองข้อที่ตรวจได้ด้วยพีชคณิต:

  • MACD > 0 ⇔ EMA12 > EMA26 ดังนั้นการตัดเส้นศูนย์ (zero-line cross) ของ MACD ก็คือ golden/death cross ของ EMA 12/26 จาก Day 55 ตัวเดียวกัน แค่วาดเป็นกราฟต่างหาก
  • Hist > 0 ⇔ MACD > Signal ดังนั้นการตัดกันของ MACD กับ Signal (signal cross) ก็คือฮิสโทแกรมเปลี่ยนเครื่องหมาย

ตัวอย่างด้วยมือ (อัปเดตหนึ่งแท่ง)

เมื่อวาน EMA12 = 52.00, EMA26 = 50.00 (MACD = 2.00), Signal = 1.50 วันนี้ราคาปิด 56

EMA12 = 52 + (2/13) × (56 − 52) = 52.6154 · EMA26 = 50 + (2/27) × (56 − 50) = 50.4444 ⇒ MACD = 2.1709

Signal = 1.50 + 0.2 × (2.1709 − 1.50) = 1.6342 ⇒ Hist = 2.1709 − 1.6342 = +0.5368 (EMA9 มี α = 2/10 = 0.2)

ลองลากราคาปิดลงมาที่ราว 50: EMA ขยับช้ากว่าราคามาก MACD แทบไม่ลดทันที แต่ฮิสโทแกรมเปลี่ยนเครื่องหมายก่อน เพราะ Signal ตอบสนองช้ากว่า MACD อีกชั้น นี่คือเหตุผลที่ฮิสโทแกรมถูกเรียกว่า "สัญญาณเร็วกว่า" แต่ก็แลกกับสัญญาณหลอกที่มากกว่า

MACD คือตัวประมาณความชัน

EMA ที่ α = 2/(N+1) ล้าหลังราคาเฉลี่ย (N−1)/2 แท่ง (Day 55) ถ้าราคาขึ้นเป็นเส้นตรงด้วยความชัน s บาทต่อแท่ง EMA12 จะอยู่ใต้ราคา 5.5s และ EMA26 อยู่ใต้ราคา 12.5s ดังนั้น:

MACD → (26 − 12) ÷ 2 × s = 7s  ·  Hist ≈ 4 × (MACDt − MACDt−1)
ราคาขึ้นเส้นตรง s บาท/แท่ง ⇒ MACD นิ่งที่ 7s และ Signal ตามทันที่ 7s ⇒ Hist = 0 · Signal ล้าหลัง (9−1)/2 = 4 แท่ง ฮิสโทแกรมจึงเป็น 4 เท่าของอัตราเปลี่ยนของ MACD ต่อแท่ง

ตรวจเชิงตัวเลข: ราคา 0, 1, 2, … (s = 1) ให้ MACD = 7.0000 และ Signal = 7.0000 ฮิสโทแกรม ≈ 0 ส่วนถ้า MACD เพิ่มทีละ 0.1 ต่อแท่ง ฮิสโทแกรมคงที่ที่ 0.40 พอดี ความหมายคือ MACD ≈ ความเร็ว (velocity) ของราคา และ ฮิสโทแกรม ≈ ความเร่ง (acceleration) ในหน่วยที่ล่าช้า ราคาไม่ต้องถอยลงเลย แค่ขึ้นช้าลง ฮิสโทแกรมก็ติดลบแล้ว

เมื่อ MACD อยู่ใต้ Signal ขณะราคายังขึ้น ไม่ได้แปลว่า "ราคาจะลง" แปลเพียงว่าราคาขึ้นช้าลงกว่าช่วงที่ผ่านมา ตำราหลายเล่มแปลสัญญาณเป็นคำทำนาย ซึ่งเป็นการอ่านเกินสิ่งที่สูตรบอก

ข้อควรระวัง: MACD มีหน่วยเป็นบาท

เพราะ MACD เป็นผลต่างของราคา ค่าของมันขึ้นกับระดับราคา หุ้น ก. ราคา 50 บาท EMA26 = 50 และ MACD = 1.0 หุ้น ข. ราคา 500 บาท MACD = 5.0 ดูเหมือน ข. "แรงกว่า" 5 เท่า แต่เทียบเป็นสัดส่วน:

PPO = MACD ÷ EMA26 × 100 (%)
หุ้น ก. 1.0 ÷ 50 × 100 = 2.00% · หุ้น ข. 5.0 ÷ 500 × 100 = 1.00% ⇒ ก. แรงกว่า 2 เท่าในแง่สัดส่วน (PPO = percentage price oscillator)

เมื่อเปรียบเทียบข้ามหุ้น หรือเทียบหุ้นตัวเดียวกันข้ามช่วงที่ราคาต่างกันมาก ใช้ PPO แทน MACD ดิบ

ความหมายของผลนี้

MACD ไม่ได้ให้ข้อมูลใหม่ มันคือการจัดรูปของราคาที่ผ่านมาให้อ่านเป็นความเร็วและความเร่ง ใน Day 55–56 ที่เห็นแล้วว่า SMA, EMA, RSI ล้วนเป็นฟังก์ชันของราคาในอดีต MACD ก็เป็นเช่นเดียวกัน

ถ้าตลาดมีโมเมนตัมจริง (ราคาที่ขึ้นแล้วมีแนวโน้มขึ้นต่อ) MACD เป็นเครื่องมือหยาบที่จับได้ แต่ต้องพิสูจน์นอกตัวอย่าง (out-of-sample) หลังหักต้นทุน ก่อนเชื่อ ไม่ใช่เชื่อเพราะกราฟตัวอย่างสวย

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
import numpy as np

def ema(x, n):
    a = 2 / (n + 1)
    o = np.empty(len(x)); o[0] = x[0]
    for i in range(1, len(x)):
        o[i] = o[i - 1] + a * (x[i] - o[i - 1])
    return o

def macd(p, f=12, s=26, g=9):
    m = ema(p, f) - ema(p, s)
    sig = ema(m, g)
    return m, sig, m - sig

# อัปเดตหนึ่งแท่งด้วยมือ
e12, e26, sg, c = 52.0, 50.0, 1.5, 56
e12 += 2 / 13 * (c - e12); e26 += 2 / 27 * (c - e26)
m = e12 - e26; sg += 0.2 * (m - sg)
print(m, sg, m - sg)                 # 2.1709  1.6342  0.5368

# ราคาขึ้นเส้นตรง s = 1 => MACD = 7s
x = np.arange(600.0)
m, sig, h = macd(x)
print(m[-1], sig[-1], h[-1])         # 7.0  7.0  ~0

# จำลองเดินสุ่ม (sigma = 1.2% ต่อแท่ง)
rng = np.random.default_rng(57)
p = 100 * np.exp(np.cumsum(rng.normal(0, 0.012, 400_000)))
m, sig, h = macd(p)
print((m > 0).mean())                # ~0.50
bull = np.where((h[1:] > 0) & (h[:-1] <= 0))[0] + 1
print(len(bull) / len(p) * 250)      # ~10.28 ครั้งต่อ 250 แท่ง

ทดสอบความเข้าใจ

1. เมื่อวาน EMA12 = 40.00, EMA26 = 38.00, Signal = 1.60 วันนี้ราคาปิด 44 จงหา MACD, Signal และ Hist ใหม่ (α = 2/13, 2/27, 0.2)

ดูเฉลย
EMA12 = 40 + (2/13) × 4 = 40.6154 · EMA26 = 38 + (2/27) × 6 = 38.4444 ⇒ MACD = 2.1709 · Signal = 1.60 + 0.2 × (2.1709 − 1.60) = 1.7142 ⇒ Hist = +0.4568 ตัวเลข MACD เท่ากับตัวอย่างในบทพอดีเพราะ (ราคา − EMA) ทั้งสองเท่ากัน (4 และ 6)

2. ราคาขึ้นเป็นเส้นตรง 0.5 บาทต่อแท่งมานานมาก MACD (12, 26, 9) จะนิ่งที่ค่าเท่าไร และฮิสโทแกรมเท่าไร เพราะอะไร

ดูเฉลย
EMA12 ล้าหลัง (12−1)/2 = 5.5 แท่ง EMA26 ล้าหลัง 12.5 แท่ง ผลต่าง 7 แท่ง × 0.5 = 3.5 บาท Signal ตามทันที่ 3.5 ฮิสโทแกรม = 0 เพราะ MACD ไม่เปลี่ยนแล้ว ฮิสโทแกรมสัมพันธ์กับการเปลี่ยนของความชัน ไม่ใช่ตัวความชัน

3. หุ้น ก. EMA26 = 80 บาท MACD = 2.0 หุ้น ข. EMA26 = 400 บาท MACD = 6.0 ตัวไหนมีโมเมนตัมแรงกว่าในแง่สัดส่วน

ดูเฉลย
PPO ก. = 2 ÷ 80 × 100 = 2.50% · PPO ข. = 6 ÷ 400 × 100 = 1.50% ⇒ ก. แรงกว่า แม้ MACD ดิบของ ข. จะมากกว่า 3 เท่า เพราะ MACD มีหน่วยเป็นบาท ต้องหารด้วยระดับราคาก่อนเทียบ

สรุป 3 บรรทัด

1. MACD = EMA12 − EMA26, Signal = EMA9(MACD), Hist = MACD − Signal ตัดเส้นศูนย์ = EMA cross ของ Day 55 ส่วนตัดกับ Signal = ฮิสโทแกรมเปลี่ยนเครื่องหมาย

2. ราคาขึ้นเส้นตรง s บาทต่อแท่ง MACD นิ่งที่ 7s ฮิสโทแกรม ≈ 4 × การเปลี่ยนของ MACD ต่อแท่ง จึงอ่านเป็นความเร็วและความเร่งที่ล่าช้า และ MACD มีหน่วยเป็นบาท ต้องใช้ PPO เมื่อเทียบข้ามหุ้น

3. ในโลกสุ่ม สัญญาณตัดเกิดราว 10 ครั้งต่อ 250 แท่ง ราคาหลังสัญญาณไม่ต่างจากฐาน และกฎตัดกันเสียต้นทุนราว 3.6% ต่อปี ต้องทดสอบนอกตัวอย่างหลังหักต้นทุนก่อนเชื่อ
