เทรด (trading) vs ลงทุน (investing)

ทั้งสองอย่างคือการซื้อขายสินทรัพย์ แต่ต่างกันที่ แหล่งที่มาของกำไร การลงทุนคือการถือเพื่อรับส่วนแบ่งกำไรและการเติบโตของธุรกิจ (Day 28–29) ซึ่งเป็นเกมที่ผลรวมเป็นบวก (positive-sum) เพราะเศรษฐกิจโต ส่วนการเทรดคือการทำกำไรจากการที่ราคาเปลี่ยนในช่วงสั้น โดยไม่สนใจว่ากิจการทำเงินเท่าไร

เลขคณิตของการเทรด

ก่อนหักต้นทุน กำไรของนักเทรดทุกคนรวมกันเป็นศูนย์ เพราะทุกกำไรคือขาดทุนของอีกฝั่ง (zero-sum) หลังหักค่าคอมมิชชัน ภาษี และ spread แล้ว ผลรวมกลายเป็นลบ (negative-sum) ค่าเฉลี่ยของทุกคนจึงต้องต่ำกว่าศูนย์ นี่คือเวอร์ชันเทรดของข้อโต้แย้งเรื่อง active vs passive ใน Day 33

หลักฐานจริง (สองงานวิจัยข้อมูลรายบุคคล)

บราซิล: ในกลุ่มคนที่เริ่มเทรดรายวันในตลาดฟิวเจอร์สหุ้นบราซิลช่วงปี 2556–2558 และเทรดต่อเนื่องเกิน 300 วัน 97% ขาดทุน มีเพียง 1.1% ที่ได้เงินมากกว่าค่าแรงขั้นต่ำ และ 0.5% ที่ได้มากกว่าเงินเดือนเริ่มต้นของพนักงานธนาคาร

ไต้หวัน: ข้อมูลทุกรายการซื้อขายปี 2538–2542 ของตลาดหลักทรัพย์ไต้หวัน การเทรดแบบ day trade เป็นกว่า 20% ของมูลค่าซื้อขายรวม และนักเทรดมากกว่า 8 ใน 10 ขาดทุนสุทธิ มีเพียงกลุ่มเล็กที่เคยทำกำไรมาก่อนที่ยังทำกำไรต่อได้ นั่นคือ ทักษะมีอยู่จริง แต่หายากมาก

ให้เทรดเดอร์ที่ไม่มีข้อได้เปรียบเลย (โอกาสถูกเท่าผิด) เทรด N รอบต่อปี แต่ละรอบได้หรือเสียเท่ากับ ±σ ของทุน และเสียต้นทุนรอบละ c (จาก Day 22 จุดคุ้มทุนต่อรอบซื้อขายในตัวอย่างของเราอยู่ราว 0.35%) จะได้ว่า

P(กำไรสุทธิ) ≈ Φ( −c√N ÷ σ )
อัตราชนะที่ต้องมี = 50% + c ÷ (2σ)

ตัวอย่าง: เต้นมีเงินเก็บ 50,000 บาท

ซื้อหุ้นแล้วถือรอบเดียว เสียต้นทุนรอบละ 0.35% = 175 บาท · ถ้าเทรดเต็มพอร์ตวันละครั้งเดือนละ 20 วัน 12 เดือน = 240 รอบ ต้นทุนสะสม 1 − 0.9965240 = 56.89% ⇒ เงินต้นเหลือ 21,554 บาท ก่อนนับว่าทายทิศราคาถูกหรือผิด ตัวเลขนี้คือเหตุผลที่ต้องเรียน Phase 3 ด้วยสายตาแบบผู้ตรวจสอบ ไม่ใช่แบบแฟนคลับ

ท่าทีของ Phase 3

เราจะเรียนเครื่องมือเทรดทุกตัว (order, กราฟ, indicator, risk management) เพราะความรู้คือเกราะกันการถูกหลอก และเพราะบางคนจะเลือกเทรดอยู่ดี แต่ทุกบทจะถามสามข้อ: ข้อได้เปรียบมาจากไหน · ต้นทุนต่อรอบเท่าไร · พิสูจน์ด้วยข้อมูลนอกตัวอย่างได้ไหม · ถ้าตอบไม่ได้ทั้งสามข้อ ให้ถือว่ายังเป็นการเสี่ยงโชค

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
from math import erf, sqrt
Phi = lambda z: 0.5 * (1 + erf(z / sqrt(2)))

def summary(N, c, s):
    drag = 1 - (1 - c) ** N
    p    = Phi(-c * sqrt(N) / s)
    need = 0.5 + c / (2 * s)
    return drag, p, need

print(summary(100, .0035, .02))
# (0.2957, 0.0401, 0.5875)   -> ต้นทุน 29.57%, โอกาสกำไร 4.01%, ต้องชนะ 58.75%

ทดสอบความเข้าใจ

1. เทรดเดอร์ไม่มีข้อได้เปรียบ ทำ 100 รอบต่อปี c = 0.35% σ = 2% · ต้นทุนสะสมต่อปีและโอกาสมีกำไรสุทธิเป็นเท่าไร

ดูเฉลย
ต้นทุนสะสม = 1 − 0.9965100 = 29.57% · z = 0.0035 × √100 ÷ 0.02 = 1.75 ⇒ P = Φ(−1.75) = 4.01% · ค่าคาดหวังติดลบ 35% (100 × 0.35%) แต่ความสุ่ม σ√N มีแค่ 20% จึงต้อง "โชคดีเกิน 1.75 เท่าของส่วนเบี่ยงเบน" ถึงจะรอด

2. ถ้า c = 0.35% เทรดเดอร์ที่ได้/เสียรอบละ 1% ต้องชนะกี่เปอร์เซ็นต์ของรอบจึงเท่าทุน และถ้ารอบละ 0.5% ล่ะ

ดูเฉลย
50% + 0.35 ÷ (2 × 1) = 67.5% · และ 50% + 0.35 ÷ (2 × 0.5) = 85% · ยิ่งเทรดเป้าเล็ก ต้นทุนยิ่งกินสัดส่วนใหญ่ของกำไรต่อรอบ อัตราชนะที่ต้องมีจึงพุ่ง นี่คือเหตุผลที่ scalping ต้องมีต้นทุนต่ำมากและข้อได้เปรียบชัดเจน

3. ทำไมเทรดเดอร์ทั้งตลาดรวมกันจึงมีผลลัพธ์เฉลี่ยต่ำกว่าศูนย์ ทั้งที่การซื้อขายเป็นเรื่องที่ "คนหนึ่งได้ อีกคนเสีย"

ดูเฉลย
ก่อนต้นทุน กำไรของฝั่งหนึ่งเท่ากับขาดทุนของอีกฝั่ง ผลรวม = 0 · ต้นทุน (ค่าคอมมิชชัน ภาษี spread) ไม่ได้ตกเป็นของใครในเกม แต่ไหลออกไปหานายหน้า ตลาด และรัฐ ⇒ ผลรวม = −(ต้นทุนรวมทั้งหมด) ค่าเฉลี่ยต่อคนจึงติดลบเสมอ · ต่างจากการลงทุนระยะยาวที่ผู้ถือได้ส่วนแบ่งกำไรกิจการ ซึ่งงอกเงยจากเศรษฐกิจ ไม่ได้มาจากคนอื่นขาดทุน

สรุป 3 บรรทัด

1. ลงทุนคือเกมที่ผลรวมเป็นบวก เทรดคือเกมที่ผลรวมเป็นศูนย์ก่อนต้นทุนและติดลบหลังต้นทุน

2. ต้นทุนโตตาม N ส่วนความสุ่มโตแค่ √N: ยิ่งเทรดถี่ ยิ่งต้องมีข้อได้เปรียบจริงมากขึ้น (ตัวอย่าง 100 รอบ เสีย 29.57% โอกาสกำไร 4.01%)

3. หลักฐานจากบราซิลและไต้หวันตรงกัน: ส่วนใหญ่ขาดทุน ผู้ชนะมีจริงแต่น้อยมาก · Phase 3 จะเรียนเครื่องมือด้วยการถามสามข้อ ข้อได้เปรียบ ต้นทุน และการพิสูจน์

พรุ่งนี้ Day 49 — โครงสร้างตลาด: order book, spread, liquidity · ต้นทุนหลักของการเทรดซ่อนอยู่ในช่องว่างระหว่างราคาซื้อกับราคาขาย พรุ่งนี้จะเปิดกระดานราคาดูว่าใครเป็นคนตั้งราคา ทำไม spread ถึงกว้างในหุ้นที่ไม่มีคนซื้อขาย และ liquidity คืออะไรในทางปฏิบัติ
