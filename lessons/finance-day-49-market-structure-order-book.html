โครงสร้างตลาด: order book, spread, liquidity

ต้นทุนก้อนใหญ่ของการเทรดไม่อยู่ในใบเสร็จนายหน้า แต่ซ่อนอยู่ในช่องว่างระหว่างราคาซื้อกับราคาขาย บทนี้เปิดกระดานราคาดูว่ามันเกิดขึ้นได้อย่างไร

กระดานราคา (order book)

ตลาดหุ้นไม่ได้มี "ราคา" เดียว ที่จริงคือรายการคำสั่งที่รออยู่สองฝั่ง ฝั่งซื้อคือ bid (ราคาที่มีคนยอมซื้อ) ฝั่งขายคือ ask หรือ offer (ราคาที่มีคนยอมขาย) แต่ละระดับราคามีจำนวนหุ้นรออยู่ เรียกว่า ความลึก (depth) ราคาที่เห็นบนแอป (ราคาล่าสุด) คือราคาของคู่ซื้อขายครั้งสุดท้ายเท่านั้น

best bid = ราคาซื้อสูงสุด · best ask = ราคาขายต่ำสุด
spread = ask − bid · mid = (ask + bid) ÷ 2 · spread% = spread ÷ mid

ถ้าอยากซื้อ ทันที ต้องยอมจ่ายที่ ask ถ้าอยากขาย ทันที ต้องยอมรับที่ bid นักเทรดที่ซื้อแล้วขายคืนทันทีจึงเสียเต็ม spread หนึ่งครั้ง ไม่ว่าราคากลางจะขยับหรือไม่ ผู้ที่รับส่วนต่างนี้คือคนที่ตั้งคำสั่งรอทั้งสองฝั่ง (ผู้ดูแลสภาพคล่อง หรือ market maker และนักลงทุนทั่วไปที่ตั้งราคารอ)

คำสั่งตลาดเดินบนกระดาน (walk the book)

คำสั่งซื้อแบบ market จะกินคำสั่งขายจากราคาต่ำสุดขึ้นไปจนครบจำนวน ถ้าจำนวนมากกว่าที่รอที่ราคาแรก ส่วนที่เหลือต้องไปซื้อที่ราคาถัดไป ราคาเฉลี่ยที่จ่ายจริงจึงแย่กว่า best ask ส่วนต่างนี้เรียกว่า ผลกระทบด้านราคา (price impact หรือ slippage) ลองดูกับกระดานสมมติ (หุ้นราคาราว 50 บาท ขั้นราคา 0.25) เลือกกระดานสภาพคล่องสูงหรือกระดานบาง แล้วเลื่อนขนาดคำสั่ง

สภาพคล่อง (liquidity) วัดอย่างไร

สภาพคล่องคือความสามารถในการซื้อขายจำนวนมากได้เร็วโดยราคาไม่ขยับมาก วัดได้สามมิติ: ความกว้าง (spread% ยิ่งแคบยิ่งดี) ความลึก (จำนวนหุ้นที่รอใกล้ราคากลาง) และ ความทนทาน (หลังมีคำสั่งใหญ่ ราคากลับมาเร็วแค่ไหน) หุ้นที่มูลค่าซื้อขายต่อวันสูงมักมีทั้งสามอย่างดี หุ้นเล็กที่ไม่มีใครซื้อขายจะมี spread กว้างและกระดานบาง จึงเข้าง่ายแต่ออกยาก

ตัวอย่าง: เต้นมีเงิน 50,000 บาท

หุ้น ก. ราคา bid 49.75 / ask 50.00 · mid = 49.875 · spread 0.25 บาท = 0.5013% ซื้อ 1,000 หุ้น (ราว 50,000 บาท) แล้วขายคืนทันที เสีย 0.25 × 1,000 = 250 บาท ก่อนค่าคอมมิชชัน · หุ้น ข. ราคา bid 3.00 / ask 3.04 spread 0.04 = 1.3245% ของ mid 3.02 และถ้าขาย 1,000 หุ้นทันทีที่กระดานบาง (ดูเครื่องมือด้านบน) จะเสียมากกว่านั้น

ต่อกับ Day 48: spread คือ c ที่ซ่อนอยู่

Day 48 ใช้ต้นทุนต่อรอบ c ≈ 0.35% (ค่าธรรมเนียมและ VAT ที่เห็นในใบยืนยัน) ถ้าเทรดหุ้น ก. ด้วย market order ต้องบวก spread 0.5013% ⇒ c ≈ 0.8529% เทรด 100 รอบต้นทุนสะสม 1 − (1 − 0.008529)100 = 57.54% (เทียบ 29.57% เมื่อมองแค่ค่าธรรมเนียม) ถ้าเป็นหุ้น ข. c ≈ 1.6761% ⇒ 81.55% ภายใน 100 รอบ ต้นทุนที่มองไม่เห็นหนักกว่าที่มองเห็นเสียอีก

ตัวเลขเป็นตัวอย่างสมมติเพื่อการสอน ค่าธรรมเนียมจริงแต่ละโบรกต่างกัน และ spread ที่เห็นเปลี่ยนตามเวลาและตามหุ้น

กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน) 
asks = [(50.00, 3000), (50.25, 5000), (50.50, 8000), (50.75, 10000)]
bids = [(49.75, 4000), (49.50, 6000), (49.25, 9000), (49.00, 12000)]

def walk(book, qty):
    left, cost = qty, 0.0
    for price, size in book:
        take = min(left, size)
        cost += take * price
        left -= take
        if left == 0:
            return cost / qty      # ราคาเฉลี่ยถ่วงน้ำหนัก (VWAP)
    return None                    # กระดานที่เห็นไม่พอ

mid = (asks[0][0] + bids[0][0]) / 2
buy = walk(asks, 8000)
print(buy, (buy - mid) / mid)      # 50.15625  0.00564 (0.564%)

ทดสอบความเข้าใจ

1. bid 19.70 / ask 19.80 ซื้อ 5,000 หุ้นด้วย market แล้วขายคืนทันทีด้วย market (ราคาไม่ขยับ) เสียเงินกี่บาท คิดเป็นกี่ % ของมูลค่าที่ซื้อ

ดูเฉลย
ซื้อที่ 19.80 ขายที่ 19.70 เสียหุ้นละ 0.10 × 5,000 = 500 บาท · มูลค่าซื้อ 99,000 บาท ⇒ 500 ÷ 99,000 = 0.505% (เทียบ mid 19.75 ได้ spread 0.5063%) · เสียเท่านี้ทั้งที่ราคาไม่ไปไหนเลย

2. กระดานขาย 50.00 × 3,000 หุ้น และ 50.25 × 5,000 หุ้น ซื้อ 5,000 หุ้นด้วย market ได้ราคาเฉลี่ยเท่าไร แย่กว่า best ask กี่ %

ดูเฉลย
(3,000 × 50.00 + 2,000 × 50.25) ÷ 5,000 = 250,500 ÷ 5,000 = 50.10 บาท · แย่กว่า best ask (50.00) อยู่ 0.10 ÷ 50.00 = 0.20% · เทียบกับ mid 49.875 คือ 0.4511% · คำสั่งยิ่งใหญ่ ราคาเฉลี่ยยิ่งเดินไกลจาก best ask

3. หุ้นราคา 9.95 บาท กับ 10.00 บาท spread ต่ำสุดที่เป็นไปได้ในรูป % ต่างกันกี่เท่า เพราะอะไร

ดูเฉลย
ที่ 9.95 tick = 0.05 ⇒ 0.05 ÷ 9.95 = 0.5025% · ที่ 10.00 tick = 0.10 ⇒ 0.10 ÷ 10.00 = 1.00% · ต่างกันราว 2 เท่า เพราะตาราง tick ขยับขั้นที่ 10 บาท · หุ้นที่ราคาเพิ่งข้ามรอยต่อจึงมีต้นทุน spread ขั้นต่ำสูงขึ้นทันที ต้องดูทั้งราคาและ tick ไม่ใช่ดูแค่ราคา

สรุป 3 บรรทัด

1. ตลาดคือกระดานคำสั่งสองฝั่ง ซื้อทันทีจ่ายที่ ask ขายทันทีได้ที่ bid ส่วนต่าง (spread) คือต้นทุนที่ซื้อแล้วขายคืนทันทีต้องเสียเสมอ (ตัวอย่าง 0.5013%)

2. คำสั่ง market ที่ใหญ่กว่าความลึกจะเดินกินหลายระดับราคา ผลกระทบด้านราคายิ่งหนักในกระดานบาง และ tick size ตั้งพื้น spread ขั้นต่ำเป็น % (ที่ 10 บาทกระโดดเป็นสองเท่า)

3. spread คือต้นทุน c ที่ซ่อนอยู่ของ Day 48: ค่าธรรมเนียม 0.35% บวก spread 0.50% ทำให้เทรด 100 รอบเสีย 57.54% ไม่ใช่ 29.57%

พรุ่งนี้ Day 50 — ประเภทคำสั่ง: market, limit, stop, stop-limit · วันนี้เห็นแล้วว่า market order จ่าย spread และเดินกระดาน พรุ่งนี้จะดูคำสั่ง limit ที่ยอมรอเพื่อเป็นฝั่งตั้งราคาแทน และ stop ที่ทำงานเมื่อราคาถึงจุดที่กำหนด พร้อมจุดอ่อนของแต่ละแบบ
