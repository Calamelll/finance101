เป้าหมายการเงิน SMART + สรุป Phase 1

13 วันที่ผ่านมาให้เครื่องมือมาทีละชิ้น: cash flow, net worth, เงินเฟ้อ, ดอกเบี้ยทบต้น, เงินสำรองฉุกเฉิน, การจัดสรรเงิน, หนี้, ภาษี, กองทุนลดหย่อนภาษี วันนี้เอาทุกชิ้นมาประกอบเป็นเป้าหมายการเงินที่ตั้งแล้ว "ทำจริงได้" ด้วยกรอบ SMART ก่อนเข้า Phase 2 เรื่องการลงทุนพรุ่งนี้

ทำไมแค่ "อยากมีเงินเก็บ" ไม่พอ

เป้าหมายการเงินที่คลุมเครือมีปัญหาสองอย่าง: วัดความคืบหน้าไม่ได้ และไม่รู้ว่าต้องทำอะไรวันนี้ "อยากมีเงินเก็บเยอะๆ" ไม่บอกว่าต้องออมเดือนละกี่บาท ไม่บอกว่าเงินก้อนนั้นเอาไว้ทำอะไร และไม่มีจุดตัดสินว่า "ถึงเป้าแล้วหรือยัง" กรอบ SMART (Specific, Measurable, Achievable, Relevant, Time-bound) แก้ปัญหานี้โดยบังคับให้เป้าหมายผูกกับตัวเลขและกรอบเวลาที่คำนวณย้อนกลับเป็นแผนปฏิบัติได้ทันที — ซึ่งพอดีกับเครื่องมือที่เรียนมาทั้ง Phase 1 นี้เลย

SMART ผูกกับเครื่องมือที่เรียนมาแล้วอย่างไร

S — Specific (เจาะจง)

ระบุว่าเงินก้อนนี้ไว้ทำอะไร ไม่ใช่แค่ "เก็บเงิน" ต้องรู้ก่อนว่าตอนนี้สถานะการเงินเป็นอย่างไร — ใช้ งบกระแสเงินสด (Day 2) ดูว่าเหลือเก็บเดือนละเท่าไร และ ความมั่งคั่งสุทธิ (Day 3) ดูว่าตอนนี้มีสินทรัพย์-หนี้สินเท่าไรเป็นจุดตั้งต้น

M — Measurable (วัดผลได้)

ตั้งจำนวนเงินและวันที่ชัดเจน เช่น "150,000 บาท ภายใน 3 ปี" ไม่ใช่ "เยอะๆ เร็วๆ" ถ้าเป้าหมายอยู่ไกลหลายปี ควรคิดผลของ เงินเฟ้อ (Day 4) ด้วย เพราะ 150,000 บาทในอีก 3 ปีซื้อของได้น้อยกว่า 150,000 บาทวันนี้เล็กน้อย

A — Achievable (ทำได้จริง)

เช็คกับ ระบบ 50/30/20 (Day 8) ว่าเงินก้อน 20% ที่กันไว้ "จ่ายตัวเองก่อน" ต่อเดือน พอสำหรับยอดที่ต้องออมต่อเดือนไหม ถ้าไม่พอ ต้องปรับเป้าหมาย (ยืดเวลา/ลดจำนวน) หรือปรับงบ ไม่ใช่ฝืนตั้งเป้าที่ทำไม่ได้แล้วเลิกกลางทาง

R — Relevant (สอดคล้องกับความสำคัญ)

จัดลำดับกับเป้าหมายอื่นที่เรียนมา — เงินสำรองฉุกเฉิน (Day 7) ควรมาก่อนเป้าหมายฟุ่มเฟือย และถ้ามี หนี้เสียดอกเบี้ยสูงอย่างบัตรเครดิต (Day 10-11) ค้างอยู่ การโปะหนี้มักคุ้มกว่าการออมเป้าหมายใหม่ เพราะดอกเบี้ยที่ประหยัดได้สูงกว่าผลตอบแทนการลงทุนทั่วไป

T — Time-bound (มีกำหนดเวลา)

กำหนดเส้นตายบังคับให้คำนวณย้อนกลับเป็นยอดออมต่อเดือนได้ทันที ยิ่งมีเวลานาน ยิ่งพึ่ง ดอกเบี้ยทบต้น (Day 5) ช่วยแบ่งเบาภาระได้มาก และใช้ Rule of 72 (Day 6) ประมาณคร่าวๆ ได้ว่าเงินก้อนนั้นจะโตเป็น 2 เท่าเมื่อไรถ้าปล่อยไว้เฉยๆ

ตัวอย่างตัวเลขจริง: เป้าหมาย SMART ของวิศวกรจบใหม่

ยังเป็นวิศวกรเงินเดือน 40,000 บาท/เดือนจาก Day 12-13 — งบ 50/30/20 (Day 8) จัดสรร 20% ไว้ออม/ลงทุน = 8,000 บาท/เดือน สมมติเงินสำรองฉุกเฉิน (Day 7) ครบแล้ว จึงตั้งเป้าหมายถัดไปแบบ SMART ได้ว่า:

"เก็บเงิน 150,000 บาท ภายใน 3 ปี เพื่อเป็นเงินดาวน์คอนโด (S) วัดผลทุกสิ้นเดือนจากยอดในบัญชี/พอร์ตลงทุน (M) ใช้ไม่เกิน 8,000 บาท/เดือนจากงบ 20% ที่กันไว้แล้ว (A) จัดลำดับรองจากเงินสำรองฉุกเฉินที่มีอยู่แล้วและไม่มีหนี้ดอกเบี้ยสูงค้าง (R) เส้นตายคือเดือนที่ 36 นับจากวันนี้ (T)"

คำถามคือต้องออมเดือนละเท่าไรถึงจะถึง 150,000 บาทใน 3 ปี — คำตอบขึ้นกับว่าเงินก้อนนี้ "นอนเฉยๆ" หรือ "เอาไปลงทุนต่อ" ด้วย

ผลตอบแทนสมมติออมเดือนละรวมที่ฝากเองตลอด 3 ปีมาจากผลตอบแทน

ที่ผลตอบแทน 8% ต่อปี เงิน 8,000 บาทที่กันไว้ต่อเดือนเหลือเผื่อไว้ใช้จ่ายอย่างอื่นได้อีกกว่า 4,000 บาท หรือจะออมเท่าเดิมแล้วร่นเป้าหมายให้เร็วขึ้นก็ได้ — นี่คือเหตุผลที่ "A: ทำได้จริง" กับ "T: มีกำหนดเวลา" ต้องคิดคู่กับผลตอบแทนที่คาดหวังเสมอ ไม่ใช่แค่หารเวลาตรงๆ

ลองคำนวณเป้าหมายของตัวเอง

ปรับระยะเวลาและอัตราผลตอบแทนสมมติ เพื่อดูว่าต้องออมเดือนละเท่าไรถึงจะถึงเป้าหมาย 150,000 บาท และมูลค่าก้อนสุดท้ายมาจาก "เงินที่ฝากเอง" กับ "ผลตอบแทนที่ทบต้น" ในสัดส่วนเท่าไร

สัดส่วนของเป้าหมาย 150,000 บาท
เงินที่ฝากเอง มาจากผลตอบแทนทบต้น
กล่องโค้ด (ข้ามได้ ไม่นับในเวลาอ่าน)

สูตรหายอดออมต่อเดือน (PMT) ที่ต้องใช้เพื่อให้มูลค่าอนาคต (future value) ถึงเป้าหมาย เมื่อฝากทบต้นทุกเดือน ตรวจสอบด้วย Python ก่อนใส่ตัวเลขในบทเรียนแล้ว:

def pmt_needed(fv, annual_rate, years):
    i = annual_rate / 12
    n = years * 12
    if annual_rate == 0:
        return fv / n
    return fv * i / ((1 + i) ** n - 1)

fv = 150000
for years in (1, 2, 3, 4, 5):
    row = [round(pmt_needed(fv, r, years)) for r in (0.0, 0.02, 0.08)]
    print(years, row)
# 1 [12500, 12386, 12048]
# 2 [6250, 6131, 5784]
# 3 [4167, 4046, 3700]
# 4 [3125, 3004, 2662]
# 5 [2500, 2379, 2041]

ทดสอบความเข้าใจ

1. ทำไมเป้าหมาย "อยากมีเงินเก็บเยอะๆ" ถึงไม่ผ่านเกณฑ์ SMART แม้แต่ข้อเดียว?

ดูเฉลย
ไม่ระบุว่าเงินก้อนนี้ไว้ทำอะไร (ไม่ Specific) ไม่มีตัวเลขหรือวันที่ให้วัดว่าถึงเป้าหรือยัง (ไม่ Measurable/Time-bound) และประเมินไม่ได้ว่าเป็นไปได้จริงหรือไม่เพราะไม่รู้ว่า "เยอะๆ" คือเท่าไร (ไม่ Achievable) เป้าหมายแบบนี้จึงคำนวณย้อนกลับเป็นแผนปฏิบัติรายเดือนไม่ได้เลย

2. ทำไมยอดออมต่อเดือนที่ต้องใช้ถึงลดลงเมื่อสมมติผลตอบแทนสูงขึ้น (0% → 2% → 8%) ทั้งที่เป้าหมายเงินก้อนสุดท้ายเท่าเดิม?

ดูเฉลย
เพราะส่วนหนึ่งของเป้าหมาย 150,000 บาท ถูกเติมเต็มด้วย "ดอกเบี้ยทบต้น" ที่งอกจากเงินต้นเอง ยิ่งผลตอบแทนต่อปีสูง ยิ่งให้ผลตอบแทนช่วยแบกภาระมากขึ้น เงินที่ต้องฝากเองต่อเดือนจึงลดลง หลักการเดียวกับ Day 5 (ดอกเบี้ยทบต้น) แค่กลับด้านเป็น "รู้เป้าหมาย หาย้อนกลับว่าต้องฝากเท่าไร" แทนที่จะหาว่าฝากเท่านี้แล้วจะได้เท่าไร

3. ในลำดับ SMART ทำไม "R (Relevant)" ถึงบอกว่าควรโปะหนี้บัตรเครดิตก่อนเริ่มเป้าหมายออมเงินใหม่?

ดูเฉลย
เพราะดอกเบี้ยบัตรเครดิตที่ค้างจ่ายสูงกว่าผลตอบแทนที่คาดหวังจากการออม/ลงทุนทั่วไปมาก การ "ประหยัดดอกเบี้ย" จากการโปะหนี้จึงให้ผลตอบแทนที่แน่นอนและสูงกว่าการเอาเงินไปออมเป้าหมายใหม่ขนานกัน ตั้งเป้าหมายให้สอดคล้องกับลำดับความสำคัญทางการเงินจริง ไม่ใช่แค่สิ่งที่อยากได้

ทวน: เงินเดือน 40,000 บาท ใช้ระบบ 50/30/20 แบ่งเป็นสัดส่วนออม/ลงทุน 20% ได้เดือนละกี่บาท และหลักการ "pay yourself first" ต่างจากการออม "เงินที่เหลือ" ท้ายเดือนอย่างไร?

ดูเฉลย
20% ของ 40,000 บาท = 8,000 บาท/เดือน หลักการ pay yourself first คือกันเงินก้อนออม/ลงทุนออกจากบัญชีทันทีที่เงินเดือนเข้า ก่อนใช้จ่ายอย่างอื่น ต่างจากการรอดูว่า "เหลือเท่าไรค่อยออม" ซึ่งมักจบที่เหลือน้อยหรือไม่เหลือเลย เพราะค่าใช้จ่ายมักขยายเต็มพื้นที่ที่มีอยู่เสมอ
ตอบผิดหรือลังเล? → ทบทวน Day 8: ระบบจัดสรรเงิน 50/30/20 และ pay yourself first

ทวน: บัตรเครดิตคิดดอกเบี้ยแบบขั้นบันได (tiered interest) ต่างจากดอกเบี้ยเงินกู้แบบคงที่ทั่วไปอย่างไร และทำไมถึงเป็น "หนี้เสีย" ที่ควรโปะก่อนเป้าหมายอื่น?

ดูเฉลย
ดอกเบี้ยบัตรเครดิตมักคิดจากยอดคงค้างในอัตราสูง และถ้าจ่ายขั้นต่ำ ดอกเบี้ยจะคำนวณซ้ำบนยอดที่ยังไม่ได้จ่าย ทำให้หนี้ก้อนเล็กบานเป็นก้อนใหญ่ได้เร็วกว่าที่คิด ต่างจากหนี้ดีอย่างสินเชื่อบ้านที่ดอกเบี้ยต่ำกว่ามากและมักมีสินทรัพย์หนุนหลัง อัตราดอกเบี้ยที่สูงกว่าผลตอบแทนการลงทุนทั่วไปคือเหตุผลที่ควรจัดลำดับโปะหนี้นี้ก่อนตั้งเป้าหมายออมใหม่
ตอบผิดหรือลังเล? → ทบทวน Day 11: บัตรเครดิตและกับดักดอกเบี้ยขั้นบันได

สรุป 3 บรรทัด

1. เป้าหมายการเงินที่ใช้ได้จริงต้องเจาะจง วัดผลได้ ทำได้จริง สอดคล้องกับลำดับความสำคัญ และมีกำหนดเวลา (SMART) — ไม่ใช่แค่ "อยากมีเงินเก็บ"

2. ยอดออมต่อเดือนที่ต้องใช้เพื่อถึงเป้าหมายลดลงเมื่อผลตอบแทนสูงขึ้น เพราะดอกเบี้ยทบต้นช่วยแบ่งเบาภาระบางส่วนแทนเงินที่ต้องฝากเอง

3. Phase 1 ให้เครื่องมือคำนวณพื้นฐานครบชุด (cash flow, net worth, เงินเฟ้อ, ดอกเบี้ยทบต้น, เงินสำรองฉุกเฉิน, การจัดสรรเงิน, หนี้, ภาษี) — Phase 2 ที่กำลังจะเริ่มจะเอาเครื่องมือชุดนี้ไปใช้กับการลงทุนจริง

พรุ่งนี้ Day 15 — การลงทุนคืออะไร ต่างจากการออมและการพนัน เปิด Phase 2: การลงทุนระยะยาว (Day 15-47)
